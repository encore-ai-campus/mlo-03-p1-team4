# crawler/data

이 폴더는 크롤러가 사이트맵 기준선과 로컬 점검 자료를 보관하는 런타임 경로입니다.

- `sitemap_ids.json`은 `baseline` 실행이 생성·갱신합니다. 처음에는 폴더가 비어 있어도 됩니다.
- 크롤러가 폴더를 만들 수 있지만, 배포 시 실행 계정이 이 경로에 쓸 수 있도록 권한을 확인합니다.
- 출처별 실행 결과는 MariaDB `crawl_jobs`, 정규화한 크롤 결과는 MongoDB `crawl.crawl_raw`에 기록합니다.
- 이 폴더의 표본·실행 자료는 업체명 등 공개하면 안 되는 정보가 포함될 수 있어 Git에 올리지 않습니다. 기존 자료를 임의로 삭제하지 않습니다.
