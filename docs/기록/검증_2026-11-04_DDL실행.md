# DDL·MongoDB 초기화 실행 검증

2026-11-04 · 공동(DB 대신 실행) · 대상: `docs/db/spacecube_mariadb.sql`, `docs/db/mongo_init.js`

## 1. 결론

- **MariaDB DDL은 그대로 쓸 수 있습니다.** 로컬 MariaDB 11.8.9에서 오류 없이 표 12개, 뷰 1개, CHECK 12개가 만들어졌고 제약 시험 29건이 모두 기대대로 나왔습니다.
- **MongoDB 초기화도 그대로 쓸 수 있습니다.** MongoDB 7.0.45(Docker)에서 컬렉션 3개와 인덱스 12개가 만들어졌고 시험 13건이 모두 통과했습니다. 다시 돌려도 오류가 나지 않습니다.
- **고쳐야 할 설정 1건:** `sql_mode`에 `STRICT_TRANS_TABLES`가 없으면 잘못된 값이 오류 없이 저장됩니다. RDS 파라미터 그룹과 앱 연결 두 곳에서 STRICT를 겁니다(아래 3절).
- DDL 파일 자체는 고치지 않았습니다. 머리말의 상태 줄만 바꿨습니다.

## 3. 찾은 것

| # | 내용 | 영향 | 처리 |
| --- | --- | --- | --- |
| 1 | `sql_mode`가 STRICT가 아니면(예: `NO_ENGINE_SUBSTITUTION`만) `method='cash'`가 빈 값 `''`으로, 동의 시각을 빠뜨린 가입이 `0000-00-00 00:00:00`으로 **오류 없이** 저장됨 | 결제·동의 기록이 조용히 망가짐 | RDS 파라미터 그룹과 앱 연결(`init_command`)에서 STRICT를 걸도록 `backend/AGENTS.md`, `infra/aws/README.md`, `산출물_04`에 적음 |
| 2 | 같은 칸을 먼저 잡은 트랜잭션이 끝날 때까지 뒤 요청이 **기다림**(행 잠금) | 결제가 길어지면 뒤 요청이 연결을 잡고 대기 | 결제 트랜잭션은 짧게(외부 호출 없음). 1062 뒤에는 먼저 `rollback()` 하고 다시 읽기를 `backend/AGENTS.md`에 적음 |
| 3 | CHECK 위반은 4025로 옴 | 409로 바꾸면 안 됨 | 이미 문서 규칙(1062만 409)과 같음, 다시 적음 |
| 4 | DDL이 DB 이름 `spacecube`를 박아 둠, 다시 돌리면 `CREATE TABLE`에서 멈춤 | 테스트 스키마에 만들 때 바꿔 써야 함 | 시험 스크립트가 `spacecube_test`로 바꿔 실행. `migrations/0001_init.sql`로 옮길 때는 `CREATE DATABASE`·`USE` 줄을 빼는 것을 권장 |
| 5 | 로컬은 MariaDB 11.8, RDS는 11.4 | 큰 차이는 없을 것으로 보지만 확인 전 | 같은 날 compose의 `mariadb:11.4`(11.4.13)에서도 29건 통과. RDS에서는 파라미터 그룹 확인용으로 한 번 더 |

## 4. 환경

- MariaDB 11.8.9(Windows 서비스), 세션 `sql_mode` = `STRICT_TRANS_TABLES,ERROR_FOR_DIVISION_BY_ZERO,NO_AUTO_CREATE_USER,NO_ENGINE_SUBSTITUTION`(로컬 기본값과 같음)
- MongoDB 7.0.45, Docker 컨테이너 `spacecube-mongo`(127.0.0.1:27017만, 인증 없음, 로컬 시험용)
- 접속 정보는 `backend/.env`(git 제외)에만 둠
- 이날 Docker Desktop이 시작되지 않았음: 지난번 종료 때 남은 소켓 파일(`%LOCALAPPDATA%\Docker\run\*.sock`, `%LOCALAPPDATA%\docker-secrets-engine\engine.sock`) 때문. 두 폴더 이름을 `*.stale-날짜`로 바꿔 치우고 다시 켬. 같은 일이 생기면 Docker를 완전히 끈 뒤 같은 방법으로 치움

## 5. 이후

- 같은 날 검증한 DDL을 `db/migrations/0001_init.sql`로 옮겼다(`CREATE DATABASE`·`USE` 줄만 뺌). `check_ddl.py`를 0001 기준으로 바꿔 다시 돌려 29건 통과. `docs/db/spacecube_mariadb.sql`에는 옮겼다는 안내만 남김
