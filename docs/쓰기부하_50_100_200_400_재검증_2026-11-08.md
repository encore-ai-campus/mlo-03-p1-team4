## 조건과 판정

- 정문 http://192.168.219.218, 예약 생성·조회·취소/환불·재조회 시나리오. VU별 전용 합성 계정과 겹치지 않는 미래 슬롯.
- spawn 5 VU/s, 목표 인원 도달 후 warmup 60초 / 측정 180초 / 회복 120초. RPS는 측정 창의 모든 API 요청 합계, 예약 p95는 성공한 예약 생성(201)만 사용.
- 오류·계측 누락·p95 500ms 초과·VM CPU 60% 2표본 연속 초과 시 다음 단계 중단. 이벤트 파일/Mongo 실패 지표도 추가 감시.
- 수정된 계측: 첫 유효 표본을 기다린 후 진행, 같은 Process 객체로 CPU 차분, 호스트 여유 RAM/디스크 최소값 수정. 이번 run은 발생기/VMware host 표본 누락 없음.
