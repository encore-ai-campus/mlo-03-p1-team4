## 이 인물의 생활과 디지털 경험

지역 인물과 대담을 녹음하는 개인 콘텐츠를 만든다.

**주 기기:** 노트북

**숙련도:** 오디오 편집·환경 검토 숙련

**예약·탐색 성향:** 환경 증거·후기 우선·가격보다 작업 성공

**개인의 일정·이동·판단 조건:** 음향 장비 표기가 정숙성까지 보장하지 않으므로 구체적인 후기와 안내를 읽는다.

## 지역을 고르는 방식

- 주 활동 지역: 대구 중구
- 첫 검색: 대구 → 중구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '대구 → 남구'로 지역을 직접 바꿔 비교한다.

## 출발점에서 원하는 결과까지

녹음·설명 영상 작업을 재작업 위험을 줄이며 진행한다.

| 접점 | 행동·판단 |
| --- | --- |
| 검색 시작 | 시·도 '대구'에서 시·군·구 '중구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 후보 비교 | 음향 시설 표기와 실제 환경을 구분하고 구체적인 후기·안내를 읽는다. |
| 결정 | 핵심 환경을 판단할 근거가 충분하면 카드 모의 결제로 확정한다. |
| 예상 밖의 상황 | 후기는 많지만 필요한 소음·환경 정보는 없다. |
| 대응·분기 | 미확인 정보를 보완할 수 있는 후보를 찾고 판단이 어려우면 보류한다. |
| 방문 이후 | 내 예약을 확인해 준비한다. 완료 후에는 직접 확인한 환경 경험만 적는다. |

표는 기본 흐름과 발생 가능한 분기를 함께 보여 주며 모든 사건이 한 방문에서 반드시 발생한다는 뜻은 아닙니다.

방음이나 정숙성 등 필수 조건이 미확인이면 높은 별점만으로 예약하지 않는다.

## 판단 순서

1. 작업 환경에 관한 구체적 정보
2. 음향 시설·안내
3. 연속 시간

> “장비가 있는 것과 작업에 맞는 환경인 것은 따로 확인해야 해요.”

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
