# 성예주 — 전남광주통합특별시 광산구

> 26세 · 소규모 브랜드 제작자 | 촬영·창작형 | 공감 지도형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 신규 후보 탐색·예산 통제·명확한 안내 선호

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 전남광주통합특별시 광산구 |
| 첫 지역 검색 | 전남광주통합특별시 → 광산구 |
| 같은 시·도 내 대안 | 전남광주통합특별시 → 서구로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** NEW 후보도 검토하되 그림을 실제 사진으로 보고 작업 환경을 추정하지 않는다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 지도의 중심 인물

작은 브랜드 소개 영상을 팀원들과 촬영한다.

**바라는 결과:** 작은 프로젝트 예산 안에서 촬영 결과물을 만든다.

## 말하는 것

> “새로운 곳도 괜찮아요. 대신 설명은 충분해야 해요.”

## 생각하는 것

**신규 후보 탐색·예산 통제·명확한 안내 선호**를 우선한다.

1. 총액·최소 시간
2. 기본 작업 시설
3. 충분한 이용 안내

## 하는 행동

1. 지역 선택에서 전남광주통합특별시 → 광산구 경로를 적용하고 4명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다.
2. NEW와 낮은 가격순을 번갈아 보며 후기 수가 적어도 안내가 충분한 후보를 남긴다.
3. 기본 작업 조건과 팀 합의가 맞으면 휴대폰 모의 결제로 확정한다.

## 감정과 부담의 가설

본인의 우선 조건인 ‘총액·최소 시간’을 확인해야 안심한다. 그림만 보고 실제 배경이나 크기를 판단하기 어렵다. 같은 상황에서 결정을 서두르기보다 조건을 다시 살피려 한다.

**취하는 대응:** 일러스트의 인상으로 확신하지 않고 확인 가능한 안내와 후기로 비교한다.

**선택을 멈추는 경계:** 싼 가격 외에 필요한 정보를 확인할 수 없으면 제외한다.

## 감정과 별도로 확인할 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 스튜디오 |
| 전체 이용 인원 | 4명 |
| 희망 시간 | 주말 14~17시 · 3시간 |
| 준비·확정 시점 | 3~7일 전 |
| 총예산 | 100,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | 인터넷/WIFI·전기·의자/테이블 |

**방문 이후:** 내 예약을 확인해 작업 순서를 정한다. 완료 후 처음 쓰는 사람에게 도움이 될 후기를 적는다.

생각과 감정은 가상 설정입니다. 체류 시간이나 검색 범위만으로 실제 감정을 판단하지 않습니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.
