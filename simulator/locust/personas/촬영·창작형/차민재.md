# 차민재 — 행동 규칙형

> 촬영·창작형 | 45세 · 생활용품 도매업 운영자 | 인천
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 이 인물이 놓인 상황

신상품 카탈로그용 사진을 외주 사진가와 찍는다. 수입 상품 배송이 늦어질 수 있어 후보를 미리 조사하되 실제 상품이 도착하기 전에는 장소를 예약하지 않는다.

**목표:** 상품이 준비된 회차에만 대여료를 쓰고 네 시간 안에 촬영을 끝낸다.

**성향:** 상품 도착 후 확정·정해진 촬영량·손실 회피

## 입력 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스튜디오 |
| 인원 | 3명 |
| 시간 | 평일 9~13시, 4시간 |
| 예약 시점 | 1주 전 조사, 상품 도착 후 1~2일 전 확정 |
| 총예산 | 20만 원 이내 |
| 조정 가능 범위 | 배송에 따라 날짜 이동, 촬영량 때문에 네 시간 유지 |

## 우선순위 — 숫자는 순서이며 점수가 아님

1. 상품 도착 확정
2. 의자/테이블·전기와 반입 안내
3. 네 시간 연속 이용·총액

## 조건 → 행동 규칙

| 조건·상황 | 이 인물의 선택 |
| --- | --- |
| 상품 도착 전 | 검색·비교만 수행 |
| 상품 검수 완료·사진가 일정 확정 | 빈 칸 재조회 후 결제 |
| 네 시간 중 일부 마감 | 촬영 시간을 억지로 줄이지 않고 날짜 변경 |
| 이용 불가 확정·시작 전 | 기존 예약 취소 검토 |

## 기본 실행 흐름

1. 예상 날짜와 필수 시설로 후보를 두세 곳 조사한다.
2. 반입·이용 안내와 최소 시간, 전체 비용을 개인 문서에 적는다.
3. 상품이 도착하면 사진가와 날짜를 정하고 카드 모의 결제로 확정한다.

## 예외 처리 사례

**발생 상황:** 상품 검수에서 문제를 발견해 촬영할 물량이 확보되지 않는다.

**대응:** 확정 전이면 예약을 보류하고, 이미 확정했다면 이용 시작 전에 취소 여부를 판단한다.

**종료·보류:** 상품이 준비되지 않았으면 공간이 비어 있어도 결제하지 않는다.

## 종료 상태와 후속 행동

내 예약을 확인하고 촬영 품목을 정리한다. 완료 후 작업 동선과 반입 안내 경험을 남긴다.

**규칙 뒤의 동기:** 싼 예약보다 사용하지 못할 비용을 줄이는 것이 중요하다. 상품과 일정이 확정되면 비교를 오래 끌지 않는다.

> “공간은 미리 봐둬도, 물건이 와야 예약할 수 있어요.”

여기서 정한 규칙은 행동 시나리오의 가정입니다. 실제 사용자가 같은 조건에서 반드시 이렇게 행동한다는 확률 모델은 아닙니다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
