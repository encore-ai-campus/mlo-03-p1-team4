# 조하윤 — 프로필 카드형

> 촬영·창작형 | 21세 · 미술 전공 대학생 | 대구
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

> “장비는 가져갈 거라서, 기본 시설이랑 반입 조건만 맞으면 괜찮아요.”

## 이 사람을 기억하는 한 줄

**포트폴리오 예산 우선·기본 시설 선택·새 후보 수용**

학교에서 만든 입체 작품을 촬영해 포트폴리오에 넣으려 한다. 장비는 친구에게 빌리고 공간만 대여하므로 불필요한 시설 조건을 줄여 작은 예산에 맞는 후보를 찾는다.

## 목표 카드

작품 세 점을 두 시간 안에 촬영하고 총 대여료를 제한한다.

## 이용 조건 카드

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스튜디오 |
| 인원 | 2명 |
| 시간 | 평일 11~13시, 2시간 |
| 예약 시점 | 이용 3~5일 전 |
| 총예산 | 5만 원 이내 |
| 조정 가능 범위 | 주중 날짜·오후 시간 모두 유연 |

## 우선순위 카드

1. 총액 5만 원 이내
2. 작품 반입·이용 안내
3. 의자/테이블·전기

## 행동을 빠르게 보기

| 단계 | 행동 |
| --- | --- |
| 찾기 | 낮은 가격순으로 보며 NEW 후보도 살펴본다. |
| 비교 | 후기 수가 적더라도 필요한 시설과 작품 반입 조건이 명확하면 비교에 남긴다. |
| 결정 | 준비물로 촬영할 수 있고 예산이 맞으면 휴대폰 모의 결제로 확정한다. |
| 중단 | 대여 장비 비용을 포함해야만 가능한 후보나 최소 시간이 긴 후보는 제외한다. |

## 돌발 상황 카드

**상황:** 주말만 조회해 후보가 비싸 보인다.

**대응:** 가능한 평일로 조건을 바꿔 실제 총액과 빈 시간을 다시 비교한다. 평일이 반드시 싸다고 가정하지는 않는다.

**속마음:** 적은 예산으로도 결과를 잘 내고 싶다. 신규 공간을 고르는 것에는 비교적 부담이 적다.

## 이 방문 이후

내 예약을 확인하고 작품 운반 시간을 계획한다. 완료 후에는 학생의 소규모 촬영 경험을 후기에 남긴다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
