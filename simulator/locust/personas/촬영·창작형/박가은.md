# 박가은 — 공감 지도형

> 촬영·창작형 | 32세 · 독립 게임 개발자 | 광주
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 공감 지도의 중심 인물

팀 프로젝트의 소개 영상을 녹화하려 한다. 자기 집은 생활 소음이 많아 외부 공간을 검토하지만, 스튜디오라는 이름만으로 소음이 없거나 장비가 준비됐다고 보지 않는다.

**바라는 결과:** 게임 화면과 설명을 안정적으로 녹화할 세 시간을 확보한다.

## 말하는 것 · SAY

> “예쁜 곳보다 다시 녹화하지 않아도 될 환경인지가 중요해요.”

## 생각하는 것 · THINK

**녹화 품질 우선·설명 신뢰·여유 있는 일정**를 기준으로 선택한다.

1. 녹화 환경 관련 안내·후기
2. 인터넷·전기·의자/테이블
3. 설치 포함 연속 시간

## 하는 행동 · DO

1. 두 유형을 각각 조회하며 지역·인원·시설 조건은 같게 둔다.
2. 구체적인 이용 안내와 후기에서 작업에 필요한 근거를 찾는다.
3. 필수 환경이 확인되고 준비 시간이 충분하면 카드 모의 결제로 확정한다.

## 느끼는 것 · FEEL

처음 공개할 영상이라 결과를 잘 내고 싶고 재촬영 비용이 걱정된다. 충분한 준비 시간이 안정감을 준다.

## 부담과 도움이 되는 조건

**불편한 순간:** 후보가 많지만 모두 비슷한 일러스트라 환경 차이를 판단하기 어렵다.

**선택을 멈추는 경계:** 높은 별점 외에 녹화 적합성을 판단할 근거가 없으면 후보를 보류한다.

**취하는 대응:** 그림의 인상보다 확인 가능한 안내와 후기를 비교하며 불명확한 조건을 메모한다.

## 감정과 별도로 확인할 사실 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스튜디오·안내가 맞는 스터디룸 |
| 인원 | 2명 |
| 시간 | 평일 14~17시, 3시간 |
| 예약 시점 | 이용 10일 전 |
| 총예산 | 12만 원 이내 |
| 조정 가능 범위 | 날짜 2~3일 조정 가능, 필수 환경은 유지 |

## 이후의 경험

내 예약을 확인해 녹화 순서를 계획한다. 완료 후에는 실제 소음과 시설 경험을 자세히 기록한다.

감정과 생각은 이 인물을 설명하기 위한 가설입니다. 체류 시간이나 클릭만으로 이를 확인했다고 판단하지 않습니다.

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
