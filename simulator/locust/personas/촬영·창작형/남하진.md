# 남하진 — 19세 · 촬영·창작형

> 대학교 재학생 | 부산 수영구 | 행동 규칙형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

친구와 상품 촬영 연습을 하며 개인 포트폴리오를 만든다.

**주 기기:** 휴대전화와 노트북

**숙련도:** 공간 예약 경험 있음·가격·반입 조건 비교

**예약·탐색 성향:** 직접 장비 준비·총액 우선·평일 유연

**개인의 일정·이동·판단 조건:** 장비는 직접 가져가고 기본 시설과 반입 조건만 필요한 만큼 적용한다.

## 지역을 고르는 방식

- 주 활동 지역: 부산 수영구
- 첫 검색: 부산 → 수영구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '부산 → 해운대구'로 지역을 직접 바꿔 비교한다.

## 목표와 입력 조건

직접 준비한 장비와 소품으로 두 시간 촬영을 끝낸다.

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 스튜디오 |
| 전체 인원 | 2명 |
| 이용 시간 가정 | 평일 11~13시, 2시간 |
| 준비·확정 시점 | 3~5일 전 |
| 총예산 | 60,000원 · 전체 대여료 상한 |
| 필요한 시설 | 의자/테이블·전기 |

## 우선순위

1. 총액
2. 반입·이용 안내
3. 기본 시설·시간

## 조건 → 행동

| 상황 | 행동 |
| --- | --- |
| 먼저 볼 지역을 선택할 수 있음 | 시·도 '부산'에서 시·군·구 '수영구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 해당 지역이 미표시되거나 결과가 없음 | 본인과 동행자가 이동에 동의하면 '부산 → 해운대구'로 지역을 직접 바꿔 비교한다. |
| 조건을 검토함 | 낮은 가격순으로 보고 기본 시설과 반입 조건, 최소 시간을 확인한다. |
| 결정 기준에 부합 | 준비물로 작업할 수 있고 예산 안이면 계좌이체 모의 결제로 확정한다. |
| 불일치·중단 기준에 해당 | 불필요한 장비나 긴 최소 시간 때문에 총액이 커지면 제외한다. |
| 후보 안내에서 가져갈 준비물과 맞지 않는 제한을 발견한다. | 준비 방식을 바꿀 수 있는지 검토하고 핵심 작업이 불가능하면 다른 후보를 찾는다. |

## 종료 이후

내 예약을 확인하고 운반·설치·정리를 두 시간 안에 배치한다. 완료 후 실제 작업 경험을 쓴다.

> “장비는 가져갈 거예요. 기본 시설과 반입 조건부터 확인하고 싶어요.”

이 규칙은 해당 인물의 대표 시나리오입니다. 실제 행동 확률이나 해당 연령 전체의 법칙은 아닙니다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
