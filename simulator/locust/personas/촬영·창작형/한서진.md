# 한서진 — 사용자 여정형

> 촬영·창작형 | 27세 · 소규모 푸드 콘텐츠 제작자 | 전주
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 출발점과 목적지

완성된 디저트를 반입해 소개 영상을 찍는다. 조리시설이 필요한 촬영은 계획하지 않으며, 음식물반입가능 표시만으로 촬영 활동과 정리 규칙까지 허용된다고 생각하지 않는다.

**도달하려는 결과:** 음식 반입과 촬영이 가능한 조건에서 준비·정리 포함 세 시간 안에 작업을 마친다.

**이 여정의 성향:** 반입 규칙 우선·설치 시간 포함·날짜 유연

## 여정 지도

| 순서 | 접점 | 실제 행동 |
| --- | --- | --- |
| 1 | 검색 시작 | 지역·스튜디오·2명과 음식물반입가능 시설로 검색한다. |
| 2 | 상세·조건 비교 | 촬영 활동과 재료 반입 관련 안내를 읽고 불명확한 후보는 제외한다. |
| 3 | 판단 | 필수 규칙이 확인된 공간에서 세 시간 연속 칸을 카드 모의 결제로 확정한다. |
| 4 | 예상 밖의 상황 | 원하는 날짜에는 중간 한 칸이 마감되어 준비 시간을 포함한 세 시간을 고를 수 없다. |
| 5 | 대응·분기 | 준비·정리 시간을 줄이지 않고 다른 평일 날짜를 조회한다. |
| 6 | 방문 이후 | 내 예약에 기록된 시간을 기준으로 품목을 준비한다. 이용 후에는 실제 반입·정리 경험을 후기에 남긴다. |

지도에는 기본 흐름과 발생 가능한 분기를 함께 표시했습니다. 모든 상황이 한 방문에서 반드시 발생한다는 뜻은 아닙니다.

## 여정을 바꾸는 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스튜디오 |
| 인원 | 2명 |
| 시간 | 평일 13~16시, 3시간 |
| 예약 시점 | 이용 5~7일 전 |
| 총예산 | 10만 원 이내 |
| 조정 가능 범위 | 평일 날짜 조정 가능, 반입 규칙은 필수 |

## 판단이 어려워지는 지점

**종료·보류:** 음식 반입이 안 되거나 촬영 조건을 확인할 수 없으면 저렴해도 제외한다.

**마음의 흐름:** 촬영 자체보다 이용 규칙을 어길까 봐 걱정된다. 조건을 이해하면 과감하게 확정한다.

## 선택의 우선순위

1. 음식 반입·활동 관련 이용 안내
2. 의자/테이블·전기
3. 준비·정리 포함 시간과 총액

> “음식을 가져가도 되는지와 촬영 뒤 정리 규칙을 먼저 알고 싶어요.”

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
