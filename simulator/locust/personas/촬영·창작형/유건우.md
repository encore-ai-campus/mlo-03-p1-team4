## 2. 생활 배경과 이용 상황

과제 촬영을 위해 팀원과 외부 공간을 찾는다. 후기가 많은 곳은 예산을 넘기 쉬워 신규 후보도 살펴보지만, 기본 시설과 안내가 불분명한 곳은 피한다.

## 3. 목표와 우선순위

- 팀 예산으로 과제 촬영을 마친다.
- 촬영 가능한 조건을 직접 비교하는 경험을 쌓는다.

의사결정 기준은 다음 순서로 적용합니다.

1. 총액과 최소 이용시간
2. 인터넷·전기·의자/테이블
3. 충분한 이용 안내

## 4. 대표 이용 조건

아래 조건은 이 인물의 한 가지 대표 사례이며, 해당 유형 전체의 평균을 뜻하지 않습니다.

| 조건 | 구체적인 가정 |
| --- | --- |
| 공간 | 스튜디오 |
| 인원 | 4명 |
| 시간 | 주말 13~16시, 3시간 |
| 예약 시점 | 이용 3~7일 전 |
| 예산 | 총액 9만 원 이내 |
| 조정 가능 범위 | 토·일 중 선택 가능, 시작 시간 1시간 이동 가능 |

## 5. 검색부터 예약 확인까지

1. 스튜디오 목록과 NEW 후보를 둘러본다.
2. 필요 시설을 적용하고 낮은 가격순으로 정렬한다.
3. 후기 수가 적더라도 안내가 구체적인 후보는 비교 목록에 남긴다.
4. 팀원과 날짜를 맞춘 뒤 계좌이체 모의 결제로 예약한다.
5. 내 예약을 확인해 촬영 시간 안에 정리까지 끝낼 계획을 세운다.

## 6. 결정 기준과 중단 이유

**예약을 결정하는 조건:** 기본 촬영 조건이 분명하고 예산이 맞으면 신규 공간을 시도한다.

**중단·보류 이유:** 싼 가격 외에는 근거가 없거나 시설이 불명확하면 제외한다.

## 7. 예약 충돌·일정 변경·이용 후 행동

**다른 사람이 먼저 예약한 경우:** 같은 후보의 일요일 칸이나 다른 저가 후보를 확인한다.

**일정·인원 변경:** 팀원 일정이 바뀌면 시작 전에 취소하고 다시 합의한다. 여러 공간을 동시에 예약해 두지는 않는다.

**이용 후 후기:** 처음 이용하는 학생에게 도움이 될 준비물과 시설 경험을 남긴다.

## 8. 불편과 필요한 도움

**예상하는 불편**

- 신규 공간과 정보 부족 공간을 구별하기 어려움
- 시간표와 최소 이용시간의 관계가 낯섦

**서비스가 도와야 할 부분**

- 후기 수가 적은 이유를 추정하지 않도록 등록 정보·안내를 명확히 제공
- 최소 시간부터 연속 칸을 고르는 흐름을 이해하기 쉽게 표시

## 9. 관찰할 수 있는 행동 가설

NEW·가격순을 번갈아 탐색 → 여러 상세 → 시간 조정 → 예약 → 비교적 구체적인 후기.

행동 기록은 이 가설을 검토하는 단서입니다. 검색 횟수나 종료 지점만으로 이용자의 감정·동기·중단 이유를 확정하지 않고 인터뷰 등으로 확인합니다.

## 10. 대표 인용문

> “후기가 적어도 설명이 충분하면 괜찮아요. 과제 예산 안에서 좋은 곳을 찾고 싶어요.”

## 서비스 기준과 문서 출처

다락큐브의 검색·공간 상세·시간 조회는 비회원도 이용할 수 있고, 예약은 회원이 모의 결제로 확정합니다. 금액은 시간당 가격 × 이용 시간이며 예산 숫자는 예시입니다. 예약형 사례는 공간별 최소 이용시간 이상, 최대 4시간, 영업시간 안의 연속된 정수 시각을 전제로 합니다. 결제 화면 진입은 시간 확보를 뜻하지 않습니다.

시설 필터와 이용 안내를 구분합니다. 시설이 있다는 표시만으로 세부 성능·반입 규칙·주차 가능 대수·활동 허용을 추정하지 않습니다. 공간 그림은 일러스트이며 실제 사진을 전제로 하지 않습니다.
