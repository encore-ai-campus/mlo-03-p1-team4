# 남재원 — 강원특별자치도 동해시

> 43세 · 협력사 영업 책임자 | 업무·협업형 | 행동 규칙형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 이동 계획·주차 안내 우선·인원 고정

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 강원특별자치도 동해시 |
| 첫 지역 검색 | 강원 → 동해시 |
| 같은 시·도 내 대안 | 강원 → 삼척시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 개인 이동 계획과 주차 조건을 확인하며 지역을 넓힌다고 가까운 곳이라 단정하지 않는다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 상황과 목표

여러 담당자가 차량으로 모여 자료를 검토하는 회의를 준비한다.

**목표:** 각자 이동하는 참석자들이 계획한 시간에 한곳에 모인다.

**성향:** 이동 계획·주차 안내 우선·인원 고정

## 입력 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 강의실·스터디룸 |
| 전체 이용 인원 | 8명 |
| 희망 시간 | 평일 10~12시 · 2시간 |
| 준비·확정 시점 | 1주 전 |
| 총예산 | 110,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | 주차·TV/프로젝터 |

## 조건 → 행동

| 상황 | 선택 |
| --- | --- |
| 우선 지역이 선택 가능 | 지역 선택에서 강원 → 동해시 경로를 적용하고 8명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다. |
| 지역이 미표시되거나 결과가 없음 | 강원 → 삼척시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 결정 조건을 확인함 | 필요한 이동 조건과 수용 인원이 확인되면 카드 모의 결제로 확정한다. |
| 불일치·보류 조건에 해당 | 필수 주차 조건을 판단할 정보가 부족하거나 인원이 넘으면 보류한다. |
| 주차 시설 표시는 있지만 본인들의 차량 조건을 확인할 정보가 없다. | 미확인 조건을 가능으로 간주하지 않고 안내가 더 분명한 후보를 비교한다. |

## 비교 과정

주차 표시와 상세 이용 규칙을 함께 읽고 차량 여러 대가 가능하다고 추정하지 않는다.

1. 이동·주차 관련 안내
2. 8명 수용
3. 고정 시간·총액

## 종료 상태와 이후 행동

내 예약을 확인해 참석자에게 이용 안내를 알린다. 완료 후 실제 이동·시설 경험을 쓴다.

> “주차가 있다는 표시를 보고 우리 차가 전부 들어간다고 생각할 수는 없어요.”

규칙은 이 개인 시나리오의 가정이며 확률 모델이나 모든 지역 사용자의 행동 법칙이 아닙니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.

**자료 기준:** 프로젝트 `db/seed/regions.csv`·`db/seed/README.md`의 지역 선택값과 `docs/산출물_01_요구사항명세서.md`의 기능 범위. 행정구역 표기 근거와 지역별 파일 목록은 [지역별 목록](../지역별_목록.md)을 참고합니다.
