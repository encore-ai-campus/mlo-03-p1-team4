# 유태욱 — 행동 규칙형

> 업무·협업형 | 41세 · 해외 고객과 일하는 전문 통역사 | 인천
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 이 인물이 놓인 상황

이동 중 해외 고객과 정해진 시간에 원격 통역을 해야 한다. 접속 지연이 업무 전체에 영향을 주므로 가격 탐색보다 인터넷과 이용 시간을 우선하고, 두 후보를 미리 비교하되 실제 예약은 한 곳만 한다.

**목표:** 원격 통역을 한 시간 정확히 진행할 공간 하나를 확보한다.

**성향:** 정시 접속·한 시간 효율·대안 사전 확보

## 입력 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스터디룸 |
| 인원 | 1명 |
| 시간 | 평일 11~12시, 1시간 |
| 예약 시점 | 이용 2일 전 |
| 총예산 | 3만 5천 원 이내 |
| 조정 가능 범위 | 시간 고정, 같은 지역 내 다른 공간 허용 |

## 우선순위 — 숫자는 순서이며 점수가 아님

1. 11~12시 이용 가능·최소 1시간
2. 인터넷·전기
3. 명확한 예약 결과

## 조건 → 행동 규칙

| 조건·상황 | 이 인물의 선택 |
| --- | --- |
| 최소 이용시간이 1시간이고 시설 확인됨 | 우선 후보 유지 |
| 첫 후보 마감이 확인됨 | 같은 시간의 대안 검토 |
| 확정 결과가 불명확함 | 추가 결제 전 내 예약 확인 |
| 업무 자체가 취소되고 시작 전 | 예약 취소 |

## 기본 실행 흐름

1. 날짜·11시·1시간·1명과 인터넷·전기를 적용한다.
2. 안내가 충분한 두 후보를 비교하고 개인 메모에 대안 이름을 적는다.
3. 첫 후보의 조건과 총액이 맞으면 카드 모의 결제로 한 곳만 확정한다.

## 예외 처리 사례

**발생 상황:** 확정 전에 첫 후보의 시간이 마감된다.

**대응:** 같은 시간의 두 번째 후보를 확인한다. 다른 시각으로 임의 이동하지 않는다.

**종료·보류:** 필수 환경을 확인할 수 없거나 최소 시간이 맞지 않으면 제외한다.

## 종료 상태와 후속 행동

내 예약을 확인하고 접속 준비를 한다. 업무가 취소되면 시작 전에 예약을 취소한다.

**규칙 뒤의 동기:** 대안이 있다는 사실이 안심되지만 여러 곳을 동시에 잡아둘 필요는 없다고 생각한다.

> “통역 시작 시간은 바꿀 수 없어요. 같은 시간의 대안을 미리 봐둘게요.”

여기서 정한 규칙은 행동 시나리오의 가정입니다. 실제 사용자가 같은 조건에서 반드시 이렇게 행동한다는 확률 모델은 아닙니다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
