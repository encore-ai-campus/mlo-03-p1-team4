# 송도윤 — 62세 · 업무·협업형

> 지역 활동 기획자 | 충남 서산시 | 프로필 카드형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

지역 활동가들과 공동 프로그램의 기획안을 검토한다.

**주 기기:** 휴대전화

**숙련도:** 협업·예약 숙련·참석자 합의 중시

**예약·탐색 성향:** 참석자 동선 합의·총액·조건 유지

**개인의 일정·이동·판단 조건:** 한 사람의 거주지보다 참석자들의 이동 동의를 우선하고 필기 시설은 유지한다.

## 지역을 고르는 방식

- 주 활동 지역: 충남 서산시
- 첫 검색: 충남 → 서산시
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '충남 → 당진시'로 지역을 직접 바꿔 비교한다.

> “한 사람에게만 편한 곳보다 모두가 동의할 수 있는 곳을 찾고 싶어요.”

## 목표 카드

서로 다른 곳에서 출발하는 협업자들이 납득하는 장소를 고른다.

## 이용 조건 카드

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 스터디룸·카페형 공간 |
| 전체 인원 | 5명 |
| 이용 시간 가정 | 평일 19~21시, 2시간 |
| 준비·확정 시점 | 4~7일 전 |

| 필요한 시설 | 인터넷/WIFI·화이트보드 |

## 선택 카드

1. 참석자 지역·시간 합의
2. 필기 시설
3. 총액

| 행동 | 선택 |
| --- | --- |
| 검색 | 시·도 '충남'에서 시·군·구 '서산시'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 비교 | 지역별 후보를 같은 인원·시간으로 비교하고 브라우저 주소를 외부에서 공유한다. |
| 결정 | 참석자 동의가 모인 뒤 빈 칸을 재조회해 계좌이체 모의 결제로 확정한다. |
| 중단 | 인원이나 지역에 동의가 모이지 않으면 당일 방문에서 예약하지 않을 수 있다. |

## 돌발 상황 카드

**상황:** 한 참석자가 다른 지역의 더 싼 후보를 제안한다.

**대응:** 가격만으로 옮기지 않고 개인별 이동 계획을 다시 확인한다.

**이후:** 내 예약을 확인해 합의한 내용을 전달한다. 완료 후 협업 환경을 기록한다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
