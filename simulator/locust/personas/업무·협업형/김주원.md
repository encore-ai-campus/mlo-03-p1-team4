# 김주원 — 70세 · 업무·협업형

> 시간제 기술 자문가 | 부산 남구 | 행동 규칙형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

시간제로 자문을 이어 가며 고객과 한 시간 온라인 회의를 진행한다.

**주 기기:** 노트북

**숙련도:** 원격 협업·온라인 예약 숙련

**예약·탐색 성향:** 한 시간 정시 접속·재이용·대안 준비

**개인의 일정·이동·판단 조건:** 고정 업무 시각을 먼저 맞추고 확인된 공간이면 복잡한 비교 없이 예약한다.

## 지역을 고르는 방식

- 주 활동 지역: 부산 남구
- 첫 검색: 부산 → 남구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '부산 → 동구'로 지역을 직접 바꿔 비교한다.

## 목표와 입력 조건

정해진 원격 업무를 한 시간 정확히 진행한다.

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 스터디룸 |
| 전체 인원 | 1명 |
| 이용 시간 가정 | 평일 11~12시, 1시간 |
| 준비·확정 시점 | 1~2일 전 |
| 총예산 | 40,000원 · 전체 대여료 상한 |
| 필요한 시설 | 인터넷/WIFI·전기 |

## 우선순위

1. 고정 1시간과 최소 이용시간
2. 인터넷·전기
3. 명확한 결과

## 조건 → 행동

| 상황 | 행동 |
| --- | --- |
| 먼저 볼 지역을 선택할 수 있음 | 시·도 '부산'에서 시·군·구 '남구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 해당 지역이 미표시되거나 결과가 없음 | 본인과 동행자가 이동에 동의하면 '부산 → 동구'로 지역을 직접 바꿔 비교한다. |
| 조건을 검토함 | 이전에 쓴 후보를 먼저 보고 불가능하면 같은 조건의 대안을 확인한다. |
| 결정 기준에 부합 | 필수 환경과 한 시간이 맞으면 카드 모의 결제로 한 곳만 확정한다. |
| 불일치·중단 기준에 해당 | 핵심 업무 환경이 확인되지 않거나 최소 시간이 맞지 않으면 제외한다. |
| 결제 후 응답이 늦어 성공 여부가 불명확하다. | 추가 결제 전에 내 예약과 연결 상태를 확인한다. |

## 종료 이후

내 예약을 대조해 접속 준비를 한다. 업무가 취소되면 이용 시작 전에 취소한다.

> “업무 시작 시간은 못 바꾸니까 같은 시간의 대안을 먼저 봐둬요.”

이 규칙은 해당 인물의 대표 시나리오입니다. 실제 행동 확률이나 해당 연령 전체의 법칙은 아닙니다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
