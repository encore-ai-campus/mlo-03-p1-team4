# 윤채원 — 대전광역시 서구

> 34세 · 프로젝트 코디네이터 | 업무·협업형 | 프로필 카드형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 사전 승인·참석자 합의 후 예약

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 대전광역시 서구 |
| 첫 지역 검색 | 대전 → 유성구 |
| 같은 시·도 내 대안 | 대전 → 서구로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 세종 → 세종시 · 참석자 동의와 이동 가능 여부 확인 후 별도 검색 |

**이 사람의 이동·지역 판단:** 거주 구와 다른 합의 지역을 우선하며 세종 후보는 별도 시·도로 선택하고 장소 변경 때 승인을 다시 받는다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

> “후보를 봐둔 것하고 승인받아 확정한 건 다르죠.”

## 상황 카드

광역으로 협업하는 실무자들의 예산 승인 회의를 준비한다.

**성향:** 사전 승인·참석자 합의 후 예약

**목표:** 승인받은 총액과 참석 인원에 맞는 업무 장소를 확정한다.

## 조건 카드

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 강의실·스터디룸 |
| 전체 이용 인원 | 6명 |
| 희망 시간 | 평일 13~16시 · 3시간 |
| 준비·확정 시점 | 1주 전 탐색, 승인 후 확정 |
| 총예산 | 135,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | TV/프로젝터·의자/테이블 |

## 판단 카드

1. 예산·장소 승인
2. 수용 인원과 시설
3. 연속 세 시간

| 행동 | 이 인물의 선택 |
| --- | --- |
| 찾기 | 지역 선택에서 대전 → 유성구 경로를 적용하고 6명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다. |
| 비교 | 두세 후보의 총액·시설·시간을 개인 문서에 적어 결정자에게 전달한다. |
| 결정 기준 | 승인 뒤 빈 칸과 금액을 다시 확인해 카드 모의 결제로 확정한다. |
| 멈추는 경계 | 승인 전에는 결제하지 않으며 승인 조건과 달라지면 재확인한다. |

## 돌발 상황 카드

**발생:** 승인을 기다리는 사이 우선 후보가 마감된다.

**대응:** 동일 조건의 대안을 찾고 비용·지역이 달라지면 다시 동의를 받는다.

**이후:** 내 예약과 승인 조건을 대조해 확정 내역을 알린다. 완료 후 업무 시설을 평가한다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.

**자료 기준:** 프로젝트 `db/seed/regions.csv`·`db/seed/README.md`의 지역 선택값과 `docs/산출물_01_요구사항명세서.md`의 기능 범위. 행정구역 표기 근거와 지역별 파일 목록은 [지역별 목록](../지역별_목록.md)을 참고합니다.
