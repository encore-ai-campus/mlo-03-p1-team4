# 최경민 — 상황 시나리오형

> 업무·협업형 | 48세 · 중소기업 재무 자문가 | 창원
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 등장 인물과 시작 상황

고객사 직원들과 재무 자료를 함께 검토한다. 본인이 후보를 고르지만 대여료는 고객사의 사전 승인이 필요해 견적 성격의 개인 메모를 먼저 만든다.

**이번 장면의 목표:** 승인받은 총액과 실제 참석 인원에 맞는 회의 공간을 확보한다.

## 장면 1 — 후보를 발견하다

지역·7명·3시간과 화면 시설로 검색한다.

후보 두 개의 총액과 이용 조건을 개인 문서에 적어 승인받는다.

## 장면 2 — 계획과 다른 일이 생기다

승인을 기다리는 동안 우선 후보의 시간이 마감된다.

그 상황에서의 판단 기준은 **예산 승인 후 확정·인원 재검증·문서 비교**이다.

## 장면 3 — 다음 행동을 고르다

같은 조건의 대안을 찾고 금액이나 장소가 달라지면 다시 확인받는다.

## 결말과 다른 가능성

**대표 결말의 기준:** 승인 뒤 빈 칸과 금액을 다시 확인하고 카드 모의 결제로 확정한다.

**멈추는 경우:** 승인 전에는 결제하지 않으며 승인 금액이 달라지면 후보를 다시 검토한다.

**이후 행동:** 내 예약의 총액과 승인 내용을 대조한다. 이용 후에는 시설과 인원 적합성을 적는다.

## 장면 속 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 강의실·스터디룸 |
| 인원 | 7명 |
| 시간 | 평일 10~13시, 3시간 |
| 예약 시점 | 1주 전 탐색, 승인 후 3일 전 확정 |
| 총예산 | 9만 원 이내 |
| 조정 가능 범위 | 시간 고정, 같은 지역 내 후보 변경 가능 |

## 선택의 이유

1. 고객사 승인 금액
2. 7명 수용·TV/프로젝터
3. 이용 시간과 안내

일단 예약하고 나중에 맞추기보다 승인과 확정 내역이 일치해야 마음이 편하다.

> “승인받은 조건하고 실제 예약한 조건이 같아야 해요.”

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
