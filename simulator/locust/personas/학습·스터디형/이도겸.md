# 이도겸 — 프로필 카드형

> 학습·스터디형 | 19세 · 대학교 1학년 | 부산
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

> “두 시간은 필요 없어요. 딱 한 시간 가격부터 알고 싶어요.”

## 이 사람을 기억하는 한 줄

**짧은 이용·예산 고정·필터 단순화**

첫 대학 시험을 앞두고 친구와 서로 문제를 설명할 장소를 찾는다. 교내 장소가 찼을 때만 외부 공간을 쓰며, 많은 시설보다 두 명이 앉을 수 있는 저렴한 한 시간이 필요하다.

## 목표 카드

친구와 한 시간만 집중해 복습하고 각자 1만 원 이하로 부담한다.

## 이용 조건 카드

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스터디룸 |
| 인원 | 2명 |
| 시간 | 평일 16~17시, 1시간 |
| 예약 시점 | 전날 저녁 |
| 총예산 | 2만 원 이내 |
| 조정 가능 범위 | 같은 날 오후 1시간 이동 가능 |

## 우선순위 카드

1. 1시간 예약을 허용하는 최소 이용시간
2. 총액 2만 원 이하
3. 의자/테이블과 인터넷

## 행동을 빠르게 보기

| 단계 | 행동 |
| --- | --- |
| 찾기 | 지역·2명·1시간을 넣고 낮은 가격순으로 훑는다. |
| 비교 | 가격이 낮은 두 후보의 최소 이용시간을 먼저 확인하고 시설 안내를 읽는다. |
| 결정 | 한 시간만 이용할 수 있고 예산 안이면 휴대폰 모의 결제로 확정한다. |
| 중단 | 최소 두 시간이라면 친구와 비용을 더 내기보다 다른 후보를 찾는다. |

## 돌발 상황 카드

**상황:** 결제 화면의 선택 시간이 원래 계획보다 길게 표시된다.

**대응:** 최소 이용시간과 선택 칸을 다시 확인하고, 맞지 않으면 결제를 멈춘다.

**속마음:** 예약 경험이 적어 잘못된 시간만 결제하지 않으면 된다고 생각한다. 짧고 명확한 요약에서 안도한다.

## 이 방문 이후

내 예약에서 16~17시를 확인한다. 이용을 마친 뒤 처음 이용자에게 도움이 될 짧은 후기를 남길 수 있다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
