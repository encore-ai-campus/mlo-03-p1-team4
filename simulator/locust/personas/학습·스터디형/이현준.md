# 이현준 — 충청남도 천안시

> 26세 · 시험 준비 중인 직장인 | 학습·스터디형 | 공감 지도형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 필기 시설 우선·고정 일정·후기 확인

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 충청남도 천안시 |
| 첫 지역 검색 | 충남 → 천안시 |
| 같은 시·도 내 대안 | 충남 → 아산시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 경기 → 평택시 · 참석자 동의와 이동 가능 여부 확인 후 별도 검색 |

**이 사람의 이동·지역 판단:** 경기 후보를 볼 때는 시·도 선택부터 바꾸고 고정 시간은 그대로 유지한다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 지도의 중심 인물

스터디원들과 면접 문제를 화이트보드로 정리한다.

**바라는 결과:** 함께 필기하며 세 시간의 발표·문제 풀이를 마친다.

## 말하는 것

> “중간에 장소를 옮기지 않고 세 시간을 이어서 공부하고 싶어요.”

## 생각하는 것

**필기 시설 우선·고정 일정·후기 확인**를 우선한다.

1. 고정 시간
2. 화이트보드·이용 안내
3. 최근 구체적 후기

## 하는 행동

1. 지역 선택에서 충남 → 천안시 경로를 적용하고 4명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다.
2. 시설 관련 안내와 최근 후기 내용을 읽으며 후보를 두세 곳으로 줄인다.
3. 고정 시간과 필수 시설이 확인되고 예산 안이면 카드 모의 결제로 확정한다.

## 감정과 부담의 가설

본인의 우선 조건인 ‘고정 시간’을 확인해야 안심한다. 합의된 세 시간 중 중간 한 칸이 마감된다. 같은 상황에서 결정을 서두르기보다 조건을 다시 살피려 한다.

**취하는 대응:** 시간을 쪼개지 않고 같은 조건의 다른 공간이나 합의 가능한 날짜를 확인한다.

**선택을 멈추는 경계:** 높은 별점뿐이고 필요한 시설의 이용 조건이 모호하면 보류한다.

## 감정과 별도로 확인할 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 스터디룸·소형 강의실 |
| 전체 이용 인원 | 4명 |
| 희망 시간 | 토요일 10~13시 · 3시간 |
| 준비·확정 시점 | 7~10일 전 |
| 총예산 | 75,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | 화이트보드·전기 |

**방문 이후:** 내 예약을 확인해 모임원에게 시간을 전달한다. 완료 후에는 필기 시설과 소음을 기록한다.

생각과 감정은 가상 설정입니다. 체류 시간이나 검색 범위만으로 실제 감정을 판단하지 않습니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.
