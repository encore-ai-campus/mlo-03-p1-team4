# 조하진 — 66세 · 학습·스터디형

> 지역 역사 강좌 수강생 | 경남 진주시 | 공감 지도형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

지역 역사 강좌 동기들과 발표를 연습하려 한다.

**주 기기:** 태블릿

**숙련도:** 온라인 예매 숙련·시간 칸 예약은 처음

**예약·탐색 성향:** 설명 이해 우선·큰 글자·천천히 확인

**개인의 일정·이동·판단 조건:** 예매 경험은 많아도 시간 칸 선택은 낯설어 상태 문구와 최종 요약을 읽는다.

## 지역을 고르는 방식

- 주 활동 지역: 경남 진주시
- 첫 검색: 경남 → 진주시
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '경남 → 사천시'로 지역을 직접 바꿔 비교한다.

## 바라는 결과

모임의 날짜와 시간을 실수 없이 이해하고 직접 예약한다.

## 말하는 것

> “천천히 읽어도 괜찮으니 고른 날짜와 시간이 확실히 보이면 좋겠어요.”

## 생각하는 것

1. 읽기 쉬운 상태·안내
2. 동행 인원 수용
3. 총액

## 하는 행동

1. 시·도 '경남'에서 시·군·구 '진주시'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다.
2. 소수 후보의 설명·최소 시간·영업시간을 차례로 읽는다.
3. 선택한 날짜와 두 시간, 금액을 이해한 뒤 계좌이체 모의 결제로 확정한다.

## 부담과 도움이 되는 조건

**개인에게 중요한 제약:** 예매 경험은 많아도 시간 칸 선택은 낯설어 상태 문구와 최종 요약을 읽는다.

**걱정할 수 있는 상황:** 작은 화면에서 가능·선택·마감 상태를 헷갈린다.

**대응:** 상태 문구와 예약 요약을 읽고 필요하면 큰 화면에서 다시 확인한다.

**멈추는 경계:** 선택 상태나 성공 여부가 불분명하면 결제를 반복하지 않고 확인한다.

감정은 이 인물의 가상 상황을 이해하기 위한 가설이며 연령만으로 추정하지 않습니다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
