# 김가람 — 14세 · 학습·스터디형

> 중학생 | 서울 성북구 | 프로필 카드형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

친구와 과학 과제의 풀이를 서로 설명할 장소를 찾는다.

**주 기기:** 휴대전화

**숙련도:** 온라인 검색 숙련·공간 예약 처음

**예약·탐색 성향:** 총액 상한 고정·인원 합의 후 결제

**개인의 일정·이동·판단 조건:** 학교 공간이 없을 때만 유료 후보를 보고 둘이 나눠 낼 총액을 먼저 정한다.

## 지역을 고르는 방식

- 주 활동 지역: 서울 성북구
- 첫 검색: 서울 → 성북구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '서울 → 동대문구'로 지역을 직접 바꿔 비교한다.

> “시간당 가격보다 우리가 나눠 낼 전체 금액이 먼저예요.”

## 목표 카드

둘이 합의한 비용으로 자료를 함께 읽고 의견을 나눌 두 시간을 확보한다.

## 선택 카드

1. 총액 상한
2. 두 시간 연속 이용
3. 기본 시설

| 행동 | 선택 |
| --- | --- |
| 검색 | 시·도 '서울'에서 시·군·구 '성북구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 비교 | 낮은 가격순으로 보고 최소 이용시간과 총액을 대조한다. |
| 결정 | 필수 조건과 예산이 맞고 동행자가 동의하면 계좌이체 모의 결제로 확정한다. |
| 중단 | 최소 시간이 길어 총액이 상한을 넘으면 제외한다. |

## 돌발 상황 카드

**상황:** 후보의 시간당 가격은 저렴하지만 최소 이용시간 때문에 계획보다 오래 결제해야 한다.

**대응:** 최소 시간과 총액을 다시 계산하고 예산에 맞는 다른 후보를 찾는다.

**이후:** 내 예약에서 두 시간과 금액을 확인한다. 이용 완료 뒤 공부 환경에 대한 후기를 남길 수 있다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
