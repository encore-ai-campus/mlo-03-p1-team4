# 문정호 — 공감 지도형

> 학습·스터디형 | 67세 · 은퇴 후 지역 역사 강좌를 듣는 학습자 | 전주
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 공감 지도의 중심 인물

강좌 동기와 발표 연습을 위해 공간을 알아본다. 온라인 예매 경험은 있지만 시간 칸 예약은 낯설다. 색의 차이보다 글자로 쓰인 상태와 최종 요약을 보고 선택을 확인한다.

**바라는 결과:** 세 명이 조용히 발표를 연습할 날짜와 시간을 실수 없이 예약한다.

## 말하는 것 · SAY

> “천천히 해도 괜찮으니, 제가 고른 시간이 맞는지만 알 수 있으면 돼요.”

## 생각하는 것 · THINK

**조작 확신 우선·소수 후보·천천히 확인**를 기준으로 선택한다.

1. 읽기 쉬운 안내와 시간 상태
2. 3명 수용과 의자/테이블
3. 총액

## 하는 행동 · DO

1. 태블릿에서 글자 크기를 키워 지역과 인원으로 검색한다.
2. 두 후보의 안내를 끝까지 읽으며 최소 시간과 영업시간을 확인한다.
3. 선택한 두 시간과 금액을 이해한 뒤 계좌이체 모의 결제로 확정한다.

## 느끼는 것 · FEEL

다른 사람에게 대신 맡기기보다 스스로 해냈다는 확신을 원한다. 빠르게 넘기라는 압박이 있으면 불안해진다.

## 부담과 도움이 되는 조건

**불편한 순간:** 가능·선택·마감 상태가 색으로만 느껴져 현재 상태를 헷갈린다.

**선택을 멈추는 경계:** 어떤 시간이 선택됐는지 알 수 없으면 여러 번 누르지 않고 먼저 확인한다.

**취하는 대응:** 상태 문구와 예약 요약을 다시 확인하고 확실할 때만 결제로 넘어간다.

## 감정과 별도로 확인할 사실 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스터디룸 |
| 인원 | 3명 |
| 시간 | 평일 14~16시, 2시간 |
| 예약 시점 | 이용 7~10일 전 |
| 총예산 | 4만 5천 원 이내 |
| 조정 가능 범위 | 평일 오후 날짜 유연 |

## 이후의 경험

내 예약에서 확정 상태를 다시 확인한다. 이용 후 위치를 찾을 수 있으면 짧은 후기를 쓴다.

감정과 생각은 이 인물을 설명하기 위한 가설입니다. 체류 시간이나 클릭만으로 이를 확인했다고 판단하지 않습니다.

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.
