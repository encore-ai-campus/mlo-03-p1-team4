# 고민재 — 대구광역시 북구

> 23세 · 대학교 재학생 | 학습·스터디형 | 상황 시나리오형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 짧은 이용 우선·최소 시간 확인·비교 간결

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 대구광역시 북구 |
| 첫 지역 검색 | 대구 → 북구 |
| 같은 시·도 내 대안 | 대구 → 동구로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 최소 이용시간을 먼저 확인하고 다른 구는 시간 여유가 있을 때만 본다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 장면 1 — 이 사람의 계획

온라인 발표 전에 혼자 소리 내어 연습할 한 시간을 찾는다.

원하는 결과는 다음과 같다. 한 시간만 필요한 개인 연습을 불필요한 추가 비용 없이 끝낸다.

## 장면 2 — 지역과 후보를 좁히다

지역 선택에서 대구 → 북구 경로를 적용하고 1명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다.

최소 이용시간을 먼저 읽고 한 시간만 예약 가능한 후보만 남긴다.

## 장면 3 — 계획과 다른 상황

일부 후보에서 선택 가능한 최소 시간이 예상보다 길다.

시간을 늘리기보다 1시간을 허용하는 후보를 다시 찾는다.

## 결말의 경계

**결정 조건:** 한 시간과 필수 시설이 맞으면 휴대폰 모의 결제로 빠르게 확정한다.

**다른 결말:** 최소 두 시간 이상인 후보는 저렴해 보여도 제외한다.

**그 이후:** 내 예약의 시작·종료 시각을 확인한다. 이용 후기를 매번 쓰지는 않는다.

## 장면 속 조건과 우선순위

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 스터디룸 |
| 전체 이용 인원 | 1명 |

| 확인할 시설 | 인터넷/WIFI·전기 |

**성향:** 짧은 이용 우선·최소 시간 확인·비교 간결

1. 최소 1시간 허용
2. 고정 한 시간
3. 총액

> “한 시간만 필요한데 두 시간 비용을 낼 필요는 없잖아요.”

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.
