# 한민규 — 경기도 성남시

> 36세 · 자격시험 준비 중인 직장인 | 학습·스터디형 | 행동 규칙형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 필기 시설 우선·고정 일정·후기 확인

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 경기도 성남시 |
| 첫 지역 검색 | 경기 → 용인시 |
| 같은 시·도 내 대안 | 경기 → 성남시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 거주 시보다 모임원이 동의한 첫 검색 시를 우선하며 두 시의 후보를 수동 비교한다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 상황과 목표

스터디원들과 주말 구술 연습을 진행한다.

**목표:** 함께 필기하며 세 시간의 발표·문제 풀이를 마친다.

**성향:** 필기 시설 우선·고정 일정·후기 확인

## 입력 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 스터디룸·소형 강의실 |
| 전체 이용 인원 | 4명 |
| 희망 시간 | 토요일 10~13시 · 3시간 |
| 준비·확정 시점 | 7~10일 전 |
| 총예산 | 85,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | 화이트보드·전기 |

## 조건 → 행동

| 상황 | 선택 |
| --- | --- |
| 우선 지역이 선택 가능 | 지역 선택에서 경기 → 용인시 경로를 적용하고 4명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다. |
| 지역이 미표시되거나 결과가 없음 | 경기 → 성남시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 결정 조건을 확인함 | 고정 시간과 필수 시설이 확인되고 예산 안이면 카드 모의 결제로 확정한다. |
| 불일치·보류 조건에 해당 | 높은 별점뿐이고 필요한 시설의 이용 조건이 모호하면 보류한다. |
| 합의된 세 시간 중 중간 한 칸이 마감된다. | 시간을 쪼개지 않고 같은 조건의 다른 공간이나 합의 가능한 날짜를 확인한다. |

## 비교 과정

시설 관련 안내와 최근 후기 내용을 읽으며 후보를 두세 곳으로 줄인다.

1. 고정 시간
2. 화이트보드·이용 안내
3. 최근 구체적 후기

## 종료 상태와 이후 행동

내 예약을 확인해 모임원에게 시간을 전달한다. 완료 후에는 필기 시설과 소음을 기록한다.

> “중간에 장소를 옮기지 않고 세 시간을 이어서 공부하고 싶어요.”

규칙은 이 개인 시나리오의 가정이며 확률 모델이나 모든 지역 사용자의 행동 법칙이 아닙니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.

**자료 기준:** 프로젝트 `db/seed/regions.csv`·`db/seed/README.md`의 지역 선택값과 `docs/산출물_01_요구사항명세서.md`의 기능 범위. 행정구역 표기 근거와 지역별 파일 목록은 [지역별 목록](../지역별_목록.md)을 참고합니다.
