# 송민아 — 18세 · 학습·스터디형

> 고등학생·진학 준비생 | 충남 천안시 | 공감 지도형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

혼자 짧은 구술 발표를 녹음해 들어 볼 한 시간을 찾는다.

**주 기기:** 휴대전화

**숙련도:** 예약 숙련·선택 시간을 반복 확인

**예약·탐색 성향:** 짧은 이용 우선·최소 시간 확인·비교 간결

**개인의 일정·이동·판단 조건:** 자신의 장비를 쓰며 최소 한 시간을 허용하는 후보만 비교한다.

## 지역을 고르는 방식

- 주 활동 지역: 충남 천안시
- 첫 검색: 충남 → 천안시
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '충남 → 아산시'로 지역을 직접 바꿔 비교한다.

## 바라는 결과

한 시간만 필요한 개인 연습을 불필요한 추가 비용 없이 끝낸다.

## 말하는 것

> “한 시간만 필요한데 두 시간 비용을 낼 필요는 없잖아요.”

## 생각하는 것

1. 최소 1시간 허용
2. 고정 한 시간
3. 총액

## 하는 행동

1. 시·도 '충남'에서 시·군·구 '천안시'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다.
2. 최소 이용시간을 먼저 읽고 한 시간만 예약 가능한 후보만 남긴다.
3. 한 시간과 필수 시설이 맞으면 휴대폰 모의 결제로 빠르게 확정한다.

## 부담과 도움이 되는 조건

**개인에게 중요한 제약:** 자신의 장비를 쓰며 최소 한 시간을 허용하는 후보만 비교한다.

**걱정할 수 있는 상황:** 일부 후보에서 선택 가능한 최소 시간이 예상보다 길다.

**대응:** 시간을 늘리기보다 1시간을 허용하는 후보를 다시 찾는다.

**멈추는 경계:** 최소 두 시간 이상인 후보는 저렴해 보여도 제외한다.

감정은 이 인물의 가상 상황을 이해하기 위한 가설이며 연령만으로 추정하지 않습니다.

## 실제로 확인할 이용 조건

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 스터디룸 |
| 전체 인원 | 1명 |
| 이용 시간 가정 | 일요일 16~17시, 1시간 |
| 준비·확정 시점 | 전날 또는 당일 오전 |
| 총예산 | 20,000원 · 전체 대여료 상한 |
| 필요한 시설 | 인터넷/WIFI·전기 |

**이후 행동:** 내 예약의 시작·종료 시각을 확인한다. 이용 후기를 매번 쓰지는 않는다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
