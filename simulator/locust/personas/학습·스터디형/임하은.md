# 임하은 — 19세 · 학습·스터디형

> 대학교 재학생 | 전북 전주시 | 행동 규칙형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

대학 동기들과 팀 과제의 설명 순서를 필기하며 맞춘다.

**주 기기:** 노트북

**숙련도:** 비교·예약 숙련·시설 우선

**예약·탐색 성향:** 필기 시설 우선·고정 일정·후기 확인

**개인의 일정·이동·판단 조건:** 지역이 달라져도 정해진 시간과 화이트보드 조건을 유지한다.

## 지역을 고르는 방식

- 주 활동 지역: 전북 전주시
- 첫 검색: 전북 → 전주시
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '전북 → 완주군'로 지역을 직접 바꿔 비교한다.

## 목표와 입력 조건

함께 필기하며 세 시간의 발표·문제 풀이를 마친다.

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 스터디룸·소형 강의실 |
| 전체 인원 | 4명 |
| 이용 시간 가정 | 토요일 10~13시, 3시간 |
| 준비·확정 시점 | 7~10일 전 |
| 총예산 | 70,000원 · 전체 대여료 상한 |
| 필요한 시설 | 화이트보드·전기 |

## 우선순위

1. 고정 시간
2. 화이트보드·이용 안내
3. 최근 구체적 후기

## 조건 → 행동

| 상황 | 행동 |
| --- | --- |
| 먼저 볼 지역을 선택할 수 있음 | 시·도 '전북'에서 시·군·구 '전주시'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 해당 지역이 미표시되거나 결과가 없음 | 본인과 동행자가 이동에 동의하면 '전북 → 완주군'로 지역을 직접 바꿔 비교한다. |
| 조건을 검토함 | 시설 관련 안내와 최근 후기 내용을 읽으며 후보를 두세 곳으로 줄인다. |
| 결정 기준에 부합 | 고정 시간과 필수 시설이 확인되고 예산 안이면 카드 모의 결제로 확정한다. |
| 불일치·중단 기준에 해당 | 높은 별점뿐이고 필요한 시설의 이용 조건이 모호하면 보류한다. |
| 합의된 세 시간 중 중간 한 칸이 마감된다. | 시간을 쪼개지 않고 같은 조건의 다른 공간이나 합의 가능한 날짜를 확인한다. |

## 종료 이후

내 예약을 확인해 모임원에게 시간을 전달한다. 완료 후에는 필기 시설과 소음을 기록한다.

> “중간에 장소를 옮기지 않고 세 시간을 이어서 공부하고 싶어요.”

이 규칙은 해당 인물의 대표 시나리오입니다. 실제 행동 확률이나 해당 연령 전체의 법칙은 아닙니다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
