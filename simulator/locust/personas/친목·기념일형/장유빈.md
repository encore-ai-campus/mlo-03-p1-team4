# 장유빈 — 63세 · 친목·기념일형

> 직장인·보드게임 동호인 | 울산 북구 | 행동 규칙형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

지인들과 긴 전략 게임을 하는 모임의 장소를 맡았다.

**주 기기:** 태블릿

**숙련도:** 보드게임 커뮤니티·예약 숙련

**예약·탐색 성향:** 연속 네 시간·종료 시각 준수·재이용

**개인의 일정·이동·판단 조건:** 정리 시간을 빼고 게임만 네 시간으로 계산하지 않으며 종료 시각을 미리 공유한다.

## 지역을 고르는 방식

- 주 활동 지역: 울산 북구
- 첫 검색: 울산 → 북구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '울산 → 중구'로 지역을 직접 바꿔 비교한다.

## 목표와 입력 조건

게임·준비·정리를 최대 네 시간 안에 끝낸다.

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 카페형 공간·파티룸 |
| 전체 인원 | 6명 |
| 이용 시간 가정 | 토요일 18~22시, 4시간 |
| 준비·확정 시점 | 1주 전 |
| 총예산 | 160,000원 · 전체 대여료 상한 |
| 필요한 시설 | 의자/테이블·음식물반입가능 |

## 우선순위

1. 연속 네 시간
2. 활동·반입 안내
3. 총액·이전 이용 경험

## 조건 → 행동

| 상황 | 행동 |
| --- | --- |
| 먼저 볼 지역을 선택할 수 있음 | 시·도 '울산'에서 시·군·구 '북구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 해당 지역이 미표시되거나 결과가 없음 | 본인과 동행자가 이동에 동의하면 '울산 → 중구'로 지역을 직접 바꿔 비교한다. |
| 조건을 검토함 | 익숙한 후보를 먼저 보고 모임 규칙과 최소 시간, 마감 칸을 확인한다. |
| 결정 기준에 부합 | 시간과 활동 조건이 맞으면 계좌이체 모의 결제로 확정한다. |
| 불일치·중단 기준에 해당 | 한도를 넘는 활동 계획은 예약을 쪼개기보다 모임 구성을 다시 검토한다. |
| 준비한 활동이 네 시간을 넘길 가능성이 크다. | 정리 시간을 포함해 더 짧은 활동으로 바꾸거나 계획 자체를 조정한다. |

## 종료 이후

내 예약의 종료 시각을 참석자에게 알린다. 완료 후 시설과 정리 경험을 기록한다.

> “충분히 즐기고 정리까지 네 시간 안에 끝내면 돼요.”

이 규칙은 해당 인물의 대표 시나리오입니다. 실제 행동 확률이나 해당 연령 전체의 법칙은 아닙니다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
