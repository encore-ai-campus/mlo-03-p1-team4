# 정세아 — 사용자 여정형

> 친목·기념일형 | 37세 · 웹 기획자·독립영화 감상 모임 운영자 | 대전
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 출발점과 목적지

지인들과 이용 허용 범위 안에서 영상을 함께 보고 감상을 나눈다. 화면과 음향 시설을 확인하고, 영상을 보는 활동이 공간 안내와 맞는지 살핀다. 이용 규칙을 별점으로 대신 판단하지 않는다.

**도달하려는 결과:** 시청·대화·정리를 세 시간 안에 마칠 공간을 확보한다.

**이 여정의 성향:** 시청 시설 우선·후기 교차 확인·종료 시각 고정

## 여정 지도

| 순서 | 접점 | 실제 행동 |
| --- | --- | --- |
| 1 | 검색 시작 | 6명·세 시간·화면과 음향 시설을 적용해 두 유형을 각각 찾는다. |
| 2 | 상세·조건 비교 | 시설 관련 후기와 이용 안내를 함께 읽는다. |
| 3 | 판단 | 활동 조건과 시간이 확인된 공간을 카드 모의 결제로 확정한다. |
| 4 | 예상 밖의 상황 | 시간 선택 단계에서 끝나는 시각이 예상보다 늦어져 귀가 계획과 맞지 않는다. |
| 5 | 대응·분기 | 시작 시간과 칸 수를 재확인하고 21시 안에 끝나는 후보만 검토한다. |
| 6 | 방문 이후 | 내 예약을 확인하고 정리 시간을 포함한 진행표를 공유한다. 완료 후에는 시청 시설 경험을 기록한다. |

지도에는 기본 흐름과 발생 가능한 분기를 함께 표시했습니다. 모든 상황이 한 방문에서 반드시 발생한다는 뜻은 아닙니다.

## 여정을 바꾸는 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 카페형 공간·강의실 |
| 인원 | 6명 |
| 시간 | 토요일 18~21시, 3시간 |
| 예약 시점 | 이용 7~10일 전 |
| 총예산 | 12만 원 이내 |
| 조정 가능 범위 | 지역 조정 가능, 21시 종료 고정 |

## 판단이 어려워지는 지점

**종료·보류:** 화면은 있어도 필요한 사용 조건을 판단할 정보가 부족하면 보류한다.

**마음의 흐름:** 친구들이 함께 보는 경험을 중요하게 여기지만, 늦은 귀가 부담은 줄이고 싶다.

## 선택의 우선순위

1. TV/프로젝터·음향/마이크와 사용 안내
2. 6명 수용·세 시간 연속 이용
3. 총액과 종료 시각

> “화면만 있다고 정할 수는 없어요. 사용 안내랑 끝나는 시간까지 맞아야 해요.”

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
