# 최시윤 — 56세 · 친목·기념일형

> 직장인·동창 모임 총무 | 대전 동구 | 프로필 카드형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

여러 출발지에서 오는 동창들의 재회 모임을 조율한다.

**주 기기:** 휴대전화

**숙련도:** 모임 운영 경험 많음·문서 비교 선호

**예약·탐색 성향:** 전체 인원·이동 편의·충분한 사전 합의

**개인의 일정·이동·판단 조건:** 최종 인원과 주차 안내를 읽고 분담액에 동의가 모인 뒤 예약한다.

## 지역을 고르는 방식

- 주 활동 지역: 대전 동구
- 첫 검색: 대전 → 동구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '대전 → 중구'로 지역을 직접 바꿔 비교한다.

> “처음 정한 인원이 바뀌면 정원도 비용도 다시 확인해야 해요.”

## 목표 카드

서로 다른 출발지의 참석자들이 정원과 이동 계획에 맞게 모인다.

## 이용 조건 카드

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 카페형 공간·파티룸 |
| 전체 인원 | 10명 |
| 이용 시간 가정 | 토요일 15~18시, 3시간 |
| 준비·확정 시점 | 2~4주 전 |
| 총예산 | 220,000원 · 전체 대여료 상한 |
| 필요한 시설 | 주차·의자/테이블 |

## 선택 카드

1. 전체 인원 수용
2. 주차·이동 관련 안내
3. 합의한 총액

| 행동 | 선택 |
| --- | --- |
| 검색 | 시·도 '대전'에서 시·군·구 '동구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 비교 | 정원과 주차 안내를 확인하고 개인별 이동 계획을 참석자와 맞춘다. |
| 결정 | 인원·지역·비용에 합의가 되면 계좌이체 모의 결제로 확정한다. |
| 중단 | 정원이 부족하거나 필수 이동 조건을 확인할 수 없으면 제외한다. |

## 돌발 상황 카드

**상황:** 동행자가 추가되어 최대 수용 인원을 넘을 수 있다.

**대응:** 전체 인원을 다시 대조하고 초과하면 시작 전 취소 후 더 적합한 공간을 찾는다.

**이후:** 내 예약을 확인해 모임원에게 안내한다. 완료 후 직접 경험한 이동·시설 조건만 쓴다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
