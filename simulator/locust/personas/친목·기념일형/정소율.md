# 정소율 — 52세 · 친목·기념일형

> 직장인·가족 모임 운영자 | 서울 영등포구 | 사용자 여정형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

가족과 동행자가 함께하는 졸업 축하 모임을 준비한다.

**주 기기:** 휴대전화

**숙련도:** 가족 모임 예약 익숙

**예약·탐색 성향:** 동행자 포함 정원·낮 시간·명확한 규칙

**개인의 일정·이동·판단 조건:** 함께 오는 사람을 모두 세고 음식 반입 안내가 이번 모임과 맞는지 읽는다.

## 지역을 고르는 방식

- 주 활동 지역: 서울 영등포구
- 첫 검색: 서울 → 영등포구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '서울 → 구로구'로 지역을 직접 바꿔 비교한다.

## 출발점에서 원하는 결과까지

가족이나 동행자를 빠짐없이 인원에 포함해 모임을 준비한다.

| 접점 | 행동·판단 |
| --- | --- |
| 검색 시작 | 시·도 '서울'에서 시·군·구 '영등포구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 후보 비교 | 반입·동행 관련 안내와 최대 인원을 읽고 실제 참석 인원과 대조한다. |
| 결정 | 필수 규칙이 확인되고 참석자들이 동의하면 카드 모의 결제로 확정한다. |
| 예상 밖의 상황 | 추가 동행자가 생겨 정원과 준비 계획이 바뀐다. |
| 대응·분기 | 전체 인원을 다시 계산하고 초과하면 시작 전 취소 후 다른 공간을 검토한다. |
| 방문 이후 | 내 예약과 최종 인원을 대조해 이용 규칙을 공유한다. 완료 후 실제 경험을 적는다. |

표는 기본 흐름과 발생 가능한 분기를 함께 보여 주며 모든 사건이 한 방문에서 반드시 발생한다는 뜻은 아닙니다.

## 중단되는 지점

동행 인원을 빼야 정원이 맞거나 필요한 규칙이 미확인이면 제외한다.

## 판단 순서

1. 전체 동행자 수용·이용 규칙
2. 낮 시간과 준비물 조건
3. 총액

> “함께 가는 사람을 전부 세고 이용할 수 있는지도 먼저 봐야 해요.”

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
