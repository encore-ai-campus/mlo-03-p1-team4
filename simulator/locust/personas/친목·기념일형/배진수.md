# 배진수 — 행동 규칙형

> 친목·기념일형 | 50세 · 회사원·보드게임 모임 운영자 | 대구
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 이 인물이 놓인 상황

지인들과 길이가 긴 보드게임을 즐긴다. 서비스의 최대 네 시간 안에 준비와 정리를 포함하고, 시간이 남을 것이라고 추정해 다른 예약자의 시간까지 사용하는 계획은 세우지 않는다.

**목표:** 게임·준비·정리를 네 시간 안에 끝낼 편한 장소 하나를 확보한다.

**성향:** 최대 네 시간 활용·정시 종료·재이용 선호

## 입력 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 카페형 공간·파티룸 |
| 인원 | 6명 |
| 시간 | 토요일 18~22시, 4시간 |
| 예약 시점 | 이용 1주 전 |
| 총예산 | 16만 원 이내 |
| 조정 가능 범위 | 같은 날 시작 시각 1시간 조정 가능, 총 이용 최대 4시간 |

## 우선순위 — 숫자는 순서이며 점수가 아님

1. 의자/테이블·이용 안내
2. 네 시간 연속 칸
3. 이전 이용 경험과 총액

## 조건 → 행동 규칙

| 조건·상황 | 이 인물의 선택 |
| --- | --- |
| 네 시간 연속 칸이 비어 있음 | 시설·총액 확인 후 예약 |
| 연속 시간이 부족 | 다른 후보 또는 시작 시각 검토 |
| 계획이 최대 네 시간을 넘김 | 활동 구성 변경 |
| 반입 규칙 불일치 | 준비물 조정 또는 후보 제외 |

## 기본 실행 흐름

1. 이전에 이용한 공간 이름을 먼저 검색하고 다른 후보를 대안으로 본다.
2. 게임 모임에 맞는 이용 규칙과 음식 반입 안내를 읽는다.
3. 네 시간을 연속으로 고를 수 있고 예산이 맞으면 계좌이체 모의 결제로 확정한다.

## 예외 처리 사례

**발생 상황:** 준비한 게임이 네 시간을 넘길 가능성이 크다는 의견이 나온다.

**대응:** 한 예약의 한도를 넘기는 계획 대신 더 짧은 게임을 선택하거나 모임 구성을 바꾼다.

**종료·보류:** 세 시간만 가능하거나 이용 규칙이 모임과 맞지 않으면 제외한다.

## 종료 상태와 후속 행동

내 예약을 확인하고 정리 종료 시각까지 공유한다. 완료 후에는 테이블과 모임 이용 경험을 평가한다.

**규칙 뒤의 동기:** 충분히 놀고 싶지만 종료 시각을 지켜야 마음이 편하다. 익숙한 공간이면 준비 부담이 줄어든다.

> “네 시간 안에 정리까지 끝나는 게임으로 정하면 돼요.”

여기서 정한 규칙은 행동 시나리오의 가정입니다. 실제 사용자가 같은 조건에서 반드시 이렇게 행동한다는 확률 모델은 아닙니다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
