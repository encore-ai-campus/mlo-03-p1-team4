# 노유림 — 프로필 카드형

> 친목·기념일형 | 25세 · 광고대행사 직원 | 서울
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

> “서프라이즈여도 준비하는 사람끼리는 조건을 확실하게 알고 있어야 해요.”

## 이 사람을 기억하는 한 줄

**깜짝 모임 준비·소수 합의·준비 시간 포함**

친구의 이직을 축하하는 작은 모임을 준비한다. 주인공에게는 장소를 미리 알리지 않지만 예약을 맡은 본인은 다른 준비자와 시설·반입 규칙·총액을 확실히 맞춘다.

## 목표 카드

준비자들이 먼저 도착해 정리까지 마칠 세 시간의 장소를 확보한다.

## 이용 조건 카드

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 파티룸 |
| 인원 | 5명 |
| 시간 | 금요일 18~21시, 준비·정리 포함 3시간 |
| 예약 시점 | 이용 5~10일 전 |
| 총예산 | 15만 원 이내 |
| 조정 가능 범위 | 날짜 고정, 준비자 동의 시 시작 한 시간 이동 |

## 우선순위 카드

1. 준비물 반입·이용 안내
2. 음식물반입가능·5명 수용
3. 준비 포함 시간과 총액

## 행동을 빠르게 보기

| 단계 | 행동 |
| --- | --- |
| 찾기 | 날짜·5명·3시간과 음식물 반입 조건으로 검색한다. |
| 비교 | 장식이나 준비물을 가져가도 되는지 안내로 확인하고 다른 준비자와 후보를 비교한다. |
| 결정 | 규칙과 비용에 동의하면 휴대폰 모의 결제로 확정한다. |
| 중단 | 표시된 시설 외에 준비물 조건을 확인할 수 없으면 예약을 서두르지 않는다. |

## 돌발 상황 카드

**상황:** 후보의 이용 안내에서 계획한 준비 방식과 맞지 않는 제한을 발견한다.

**대응:** 규칙에 맞게 준비를 바꿀 수 있으면 후보를 유지하고, 핵심 준비가 불가능하면 다른 곳을 찾는다.

**속마음:** 주인공에게 즐거운 경험을 주고 싶지만 예쁜 그림만 보고 결정하는 것은 불안하다.

## 이 방문 이후

내 예약을 확인하고 준비자들에게만 시간과 이용 규칙을 전달한다. 완료 후에는 시설·반입 경험을 남긴다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
