# 문시윤 — 서울특별시 영등포구

> 34세 · 출판사 직원 | 친목·기념일형 | 프로필 카드형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 분담액·합의 우선·반입 안내 확인

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 서울특별시 영등포구 |
| 첫 지역 검색 | 서울 → 영등포구 |
| 같은 시·도 내 대안 | 서울 → 구로구로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 경기 → 광명시 · 참석자 동의와 이동 가능 여부 확인 후 별도 검색 |

**이 사람의 이동·지역 판단:** 지역이 달라질 때마다 분담액과 이동 계획을 외부 채팅방에서 확인한다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

> “총액이 같아도 나눠 낼 사람이 줄면 다시 얘기해야 해요.”

## 상황 카드

편집 동료들의 작은 축하 모임을 맡아 비용을 나눈다.

**성향:** 분담액·합의 우선·반입 안내 확인

**목표:** 모두가 동의한 비용과 이용 규칙으로 모임을 준비한다.

## 조건 카드

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 파티룸·카페형 공간 |
| 전체 이용 인원 | 6명 |
| 희망 시간 | 토요일 18~21시 · 3시간 |
| 준비·확정 시점 | 1~2주 전 |
| 총예산 | 135,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | 음식물반입가능·의자/테이블 |

## 판단 카드

1. 총액·참석자 합의
2. 반입 안내
3. 수용 인원·시간

| 행동 | 이 인물의 선택 |
| --- | --- |
| 찾기 | 지역 선택에서 서울 → 영등포구 경로를 적용하고 6명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다. |
| 비교 | 후보의 총액과 안내를 적고 브라우저 주소를 외부에서 공유한다. |
| 결정 기준 | 비용과 장소 합의가 모이면 카드 모의 결제로 확정한다. |
| 멈추는 경계 | 분담액이나 규칙에 동의가 모이지 않으면 결제를 보류한다. |

## 돌발 상황 카드

**발생:** 참석자가 줄어 1인당 분담액이 예상보다 커진다.

**대응:** 분담액을 다시 알리고 합의가 안 되면 총예산이 더 작은 후보를 찾는다.

**이후:** 내 예약의 시간과 금액을 전달한다. 완료 후 반입 안내와 실제 모임 경험을 적는다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.

**자료 기준:** 프로젝트 `db/seed/regions.csv`·`db/seed/README.md`의 지역 선택값과 `docs/산출물_01_요구사항명세서.md`의 기능 범위. 행정구역 표기 근거와 지역별 파일 목록은 [지역별 목록](../지역별_목록.md)을 참고합니다.
