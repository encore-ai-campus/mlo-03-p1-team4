## 2. 생활 배경과 이용 상황

동아리 회원들과 각자 찍은 사진을 화면으로 감상하는 모임을 준비한다. 예약은 본인이 진행하되 조건을 제대로 이해했는지 가족에게 함께 봐 달라고 하며, 빠른 결정 압박을 부담스러워한다.

## 3. 목표와 우선순위

- 회원 여섯 명이 앉아 사진을 함께 볼 장소를 확보한다.
- 날짜·시간·금액을 잘못 선택하지 않고 직접 예약한다.

의사결정 기준은 다음 순서로 적용합니다.

1. 읽고 이해하기 쉬운 예약 절차
2. TV/프로젝터·의자/테이블
3. 총액과 명확한 확정 표시

아래 조건은 이 인물의 한 가지 대표 사례이며, 해당 유형 전체의 평균을 뜻하지 않습니다.

## 5. 검색부터 예약 확인까지

1. 지역과 6명 조건으로 후보를 찾는다.
2. 시설과 이용 안내를 읽고 가족과 화면을 함께 확인한다.
3. 가능한 날짜에서 14~16시 두 칸을 선택하고 요약을 다시 읽는다.
4. 계좌이체 모의 결제를 직접 진행한다.
5. 내 예약의 확정 상태를 확인해 동아리 회원에게 시간을 알린다.

## 6. 결정 기준과 중단 이유

**예약을 결정하는 조건:** 필요한 시설이 있고 절차와 금액을 이해할 수 있으면 직접 확정한다.

**중단·보류 이유:** 예상하지 못한 조건이나 읽기 어려운 오류가 나오면 서두르지 않고 확인 후 다시 시도한다.

## 7. 예약 충돌·일정 변경·이용 후 행동

**다른 사람이 먼저 예약한 경우:** 마감된 시간이 분명하면 다른 평일 오후를 고른다. 성공 여부가 불명확하면 내 예약부터 확인한다.

**일정·인원 변경:** 모임이 취소되면 시작 전에 취소를 진행하고 상태가 취소로 바뀌었는지 확인한다.

**이용 후 후기:** 이용을 마친 뒤 후기 쓰는 위치를 찾으면 시설과 안내 경험을 짧게 남긴다.

## 8. 불편과 필요한 도움

**예상하는 불편**

- 작은 글씨·좁은 버튼·색으로만 된 상태 표시
- 예약 단계와 확정 단계를 혼동할 수 있음

**서비스가 도와야 할 부분**

- 확대 화면에서도 조작하기 쉬운 선택과 텍스트 상태 표시
- 완료 내역과 취소 결과를 다시 확인하기 쉬운 흐름

## 9. 관찰할 수 있는 행동 가설

소수 상세 긴 열람 → 잠시 확인 대기 → 직접 예약 → 내역 재확인. 긴 체류를 낮은 예약 의도로 단정하지 않는다.

행동 기록은 이 가설을 검토하는 단서입니다. 검색 횟수나 종료 지점만으로 이용자의 감정·동기·중단 이유를 확정하지 않고 인터뷰 등으로 확인합니다.

## 서비스 기준과 문서 출처

다락큐브의 검색·공간 상세·시간 조회는 비회원도 이용할 수 있고, 예약은 회원이 모의 결제로 확정합니다. 금액은 시간당 가격 × 이용 시간이며 예산 숫자는 예시입니다. 예약형 사례는 공간별 최소 이용시간 이상, 최대 4시간, 영업시간 안의 연속된 정수 시각을 전제로 합니다. 결제 화면 진입은 시간 확보를 뜻하지 않습니다.

시설 필터와 이용 안내를 구분합니다. 시설이 있다는 표시만으로 세부 성능·반입 규칙·주차 가능 대수·활동 허용을 추정하지 않습니다. 공간 그림은 일러스트이며 실제 사진을 전제로 하지 않습니다.
