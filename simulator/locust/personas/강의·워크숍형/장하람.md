# 장하람 — 울산광역시 남구

> 46세 · 사내 교육 기획자 | 강의·워크숍형 | 가상 인터뷰 메모형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 고정 대규모 일정·필수 발표 시설·빠른 확정

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 울산광역시 남구 |
| 첫 지역 검색 | 울산 → 남구 |
| 같은 시·도 내 대안 | 울산 → 중구로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 정원을 유지하며 참석자 동의가 있으면 다른 구의 후보도 별도로 검색한다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 가상 인터뷰의 문답 요지

아래는 가상 인물의 상황을 문답으로 요약한 기획 메모입니다. 실제 인터뷰나 관찰 기록으로 인용하지 않습니다.

### 어떤 일을 위해 공간을 찾나요?

외부 강사의 일정이 고정된 직무 교육 장소를 찾는다.

### 지역을 고르는 기준은 무엇인가요?

정원을 유지하며 참석자 동의가 있으면 다른 구의 후보도 별도로 검색한다.

### 무엇을 가장 먼저 확인하나요?

1. 전체 18명 수용·고정 시간
2. 발표 시설
3. 총액과 안내

### 실제로 어떻게 검색하고 비교하나요?

지역 선택에서 울산 → 남구 경로를 적용하고 18명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다.

큰 인원과 시설 조건을 먼저 적용하고 소수 후보의 안내만 집중해서 읽는다.

### 결정하거나 멈추는 조건은 무엇인가요?

**결정:** 수용 인원·고정 시간·시설이 맞으면 카드 모의 결제로 확정한다.

**보류·종료:** 한도를 넘는 인원이나 4시간 초과 일정을 억지로 끼워 넣지 않는다.

### 예상과 다른 일이 생기면 어떻게 하나요?

선택한 지역에는 조건을 모두 만족하는 결과가 보이지 않는다. 그 경우 정원이나 필수 시설을 줄이기보다 참가자들이 동의할 다른 지역을 검토한다.

## 진행자가 정리한 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 강의실 |
| 전체 이용 인원 | 18명 |
| 희망 시간 | 평일 9~13시 · 4시간 |
| 준비·확정 시점 | 1~3주 전 |
| 총예산 | 300,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | TV/프로젝터·음향/마이크 |

**방문 이후:** 내 예약을 대조해 장소를 공지한다. 완료 후 실제 시설과 교육 운영 경험을 남긴다.

> “공간이 커 보이는 것보다 정원과 고정 시간이 정확히 맞아야 해요.”

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.

**자료 기준:** 프로젝트 `db/seed/regions.csv`·`db/seed/README.md`의 지역 선택값과 `docs/산출물_01_요구사항명세서.md`의 기능 범위. 행정구역 표기 근거와 지역별 파일 목록은 [지역별 목록](../지역별_목록.md)을 참고합니다.
