# 이아진 — 행동 규칙형

> 강의·워크숍형 | 28세 · 프리랜서 번역가 겸 언어교환 모임 진행자 | 서울
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 이 인물이 놓인 상황

참가 신청을 외부에서 받아 언어교환 활동을 연다. 대여료를 나눌 최소 참가 인원이 모이기 전에는 결제하지 않으며, 공간을 확보한 뒤에도 최종 총인원은 수용 범위 안으로 관리한다.

**목표:** 참가자가 확정된 회차만 진행하고 불필요한 대여료를 줄인다.

**성향:** 최소 참가 인원 확인 후 예약·동의 대기·비용 통제

## 입력 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 강의실·카페형 공간 |
| 인원 | 진행자 포함 계획 8명, 최소 총 6명 |
| 시간 | 일요일 14~17시, 3시간 |
| 예약 시점 | 1주 전 조사, 참가 확인 후 2일 전 확정 |
| 총예산 | 9만 원 이내 |
| 조정 가능 범위 | 같은 일요일 시작 시간 1시간 조정 가능 |

## 우선순위 — 숫자는 순서이며 점수가 아님

1. 총 6명 이상 참가 확정
2. 최대 인원과 의자/테이블
3. 총액과 시간

## 조건 → 행동 규칙

| 조건·상황 | 이 인물의 선택 |
| --- | --- |
| 총 참가자 6명 미만 | 예약 보류 |
| 6명 이상 확정·공간 수용 범위 안 | 조건 재확인 후 예약 |
| 최종 총인원이 최대 인원 초과 | 더 큰 후보 검토 |
| 참가 취소로 진행 불가·시작 전 | 예약 취소 |

## 기본 실행 흐름

1. 예상 8명·3시간 조건으로 저가 후보를 조사한다.
2. 후보의 최대 인원과 안내를 확인하고 비용을 개인 메모에 적는다.
3. 총 6명 이상 확정되면 실제 총인원과 빈 칸을 재확인해 계좌이체 모의 결제로 예약한다.

## 예외 처리 사례

**발생 상황:** 확정 뒤 참가자가 빠져 대여료를 감당하기 어려워진다.

**대응:** 이용 시작 전에 진행 여부를 정해 취소한다. 추가 참가를 서비스의 예약 대기 기능으로 받는다고 가정하지 않는다.

**종료·보류:** 최소 참가자가 모이지 않으면 공간이 있어도 이번 회차를 예약하지 않는다.

## 종료 상태와 후속 행동

내 예약의 상태를 확인해 외부 참가자에게 알린다. 완료 회차의 후기에는 모임 환경을 기록한다.

**규칙 뒤의 동기:** 장소 선택보다 참가 인원 변동이 부담이다. 명확한 취소 가능 시점을 알면 비용 판단이 쉬워진다.

> “참가자가 먼저 확정돼야 해요. 빈 공간이 있다고 바로 결제할 수는 없어요.”

여기서 정한 규칙은 행동 시나리오의 가정입니다. 실제 사용자가 같은 조건에서 반드시 이렇게 행동한다는 확률 모델은 아닙니다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
