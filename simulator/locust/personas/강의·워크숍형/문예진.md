# 문예진 — 76세 · 강의·워크숍형

> 디지털 교육 자원활동가 | 경기 용인시 | 행동 규칙형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

성인 초보자의 스마트폰 학습을 보조 진행자와 함께 운영한다.

**주 기기:** 노트북

**숙련도:** 디지털 자원활동·예약 숙련

**예약·탐색 성향:** 전체 인원 계산·안내 이해·조기 준비

**개인의 일정·이동·판단 조건:** 본인은 숙련자이며 수강생·보조 인력을 모두 포함한 정원을 확인한다.

## 지역을 고르는 방식

- 주 활동 지역: 경기 용인시
- 첫 검색: 경기 → 용인시
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '경기 → 성남시'로 지역을 직접 바꿔 비교한다.

## 목표와 입력 조건

진행 인력을 포함한 전원이 들어가는 교육을 안정적으로 운영한다.

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 강의실 |
| 전체 인원 | 12명 |
| 이용 시간 가정 | 평일 13~16시, 3시간 |
| 준비·확정 시점 | 2주 전 |
| 총예산 | 140,000원 · 전체 대여료 상한 |
| 필요한 시설 | 인터넷/WIFI·TV/프로젝터·의자/테이블 |

## 우선순위

1. 전체 수용 인원
2. 필수 교육 시설
3. 명확한 안내

## 조건 → 행동

| 상황 | 행동 |
| --- | --- |
| 먼저 볼 지역을 선택할 수 있음 | 시·도 '경기'에서 시·군·구 '용인시'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 해당 지역이 미표시되거나 결과가 없음 | 본인과 동행자가 이동에 동의하면 '경기 → 성남시'로 지역을 직접 바꿔 비교한다. |
| 조건을 검토함 | 참가자뿐 아니라 강사·보조 인력까지 포함해 정원과 시설을 대조한다. |
| 결정 기준에 부합 | 일정과 모든 인원 조건이 맞으면 계좌이체 모의 결제로 확정한다. |
| 불일치·중단 기준에 해당 | 진행자를 포함하면 정원을 넘는 후보는 제외한다. |
| 참가자가 동행인을 데려오겠다고 해 총인원이 증가한다. | 정원을 다시 확인하고 초과하면 시작 전 취소 후 적합한 공간을 새로 찾는다. |

## 종료 이후

내 예약과 최종 명단을 대조한다. 완료 후 교육 환경과 안내 경험을 적는다.

> “배우러 오는 사람뿐 아니라 진행하는 사람도 인원에 넣어야죠.”

이 규칙은 해당 인물의 대표 시나리오입니다. 실제 행동 확률이나 해당 연령 전체의 법칙은 아닙니다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
