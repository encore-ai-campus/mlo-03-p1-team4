# 권정우 — 프로필 카드형

> 강의·워크숍형 | 47세 · 중소기업 품질관리 교육 담당자 | 울산
> 예약형 · 조건 충족 시 회원으로 모의 결제
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

> “싸게 찾는 것보다 내일 아홉 시에 열여섯 명이 들어갈 곳이 필요해요.”

## 이 사람을 기억하는 한 줄

**긴급 대체 공간 확보·인원·시설 고정**

사내 교육실을 쓸 수 없게 되어 예정된 교육의 대체 장소를 급히 찾는다. 참석자와 외부 강사 일정은 바꿀 수 없고, 비교를 오래 하기보다 필수 조건을 갖춘 곳을 확보해야 한다.

## 목표 카드

예정된 교육을 취소하지 않고 네 시간 안에 진행한다.

## 이용 조건 카드

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 강의실 |
| 인원 | 강사 포함 16명 |
| 시간 | 평일 9~13시, 4시간 |
| 예약 시점 | 이용 전날 오후 |
| 총예산 | 28만 원 이내 |
| 조정 가능 범위 | 날짜·시간·인원 고정, 인접 지역 허용 |

## 우선순위 카드

1. 고정 네 시간과 16명 수용
2. TV/프로젝터·음향/마이크
3. 총액과 명확한 안내

## 행동을 빠르게 보기

| 단계 | 행동 |
| --- | --- |
| 찾기 | 고정 날짜·9시·4시간·16명과 필수 시설을 한 번에 넣는다. |
| 비교 | 조건이 맞는 첫 두 후보의 안내와 총액을 확인한다. |
| 결정 | 수용 인원과 시설이 확인되면 카드 모의 결제로 빠르게 확정한다. |
| 중단 | 정원이 모자라거나 준비를 포함한 시간이 부족하면 제외한다. |

## 돌발 상황 카드

**상황:** 조건을 만족하는 후보가 검색 지역에 없다.

**대응:** 인원이나 시간을 줄이기보다 인접 지역으로 범위를 확대한다.

**속마음:** 갑작스러운 장소 변경으로 책임감이 크다. 확정 내역이 즉시 보이는 것이 중요하다.

## 이 방문 이후

내 예약을 확인해 참석자들에게 장소 변경을 안내한다. 완료 후에는 교육 시설의 실제 이용 경험을 적는다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
