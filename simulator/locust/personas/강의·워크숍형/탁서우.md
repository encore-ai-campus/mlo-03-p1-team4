# 탁서우 — 62세 · 강의·워크숍형

> 성인 회화 강사 | 경남 통영시 | 사용자 여정형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

성인 수강생의 회화 수업을 날짜마다 개별 예약한다.

**주 기기:** 태블릿

**숙련도:** 수업 운영·예약 숙련

**예약·탐색 성향:** 회차별 재이용·정시 운영·조기 확정

**개인의 일정·이동·판단 조건:** 한 주의 성공 내역과 다른 주의 날짜를 혼동하지 않고 회차별로 확인한다.

## 지역을 고르는 방식

- 주 활동 지역: 경남 통영시
- 첫 검색: 경남 → 통영시
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '경남 → 거제시'로 지역을 직접 바꿔 비교한다.

## 출발점에서 원하는 결과까지

참가자가 익숙한 시간과 환경에서 수업을 진행한다.

| 접점 | 행동·판단 |
| --- | --- |
| 검색 시작 | 시·도 '경남'에서 시·군·구 '통영시'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 후보 비교 | 이전에 쓴 공간을 먼저 보고 회차별 날짜의 빈 칸을 따로 확인한다. |
| 결정 | 해당 회차 조건이 맞으면 카드 모의 결제로 개별 확정한다. |
| 예상 밖의 상황 | 정기적으로 쓰던 시간 중 이번 회차만 마감된다. |
| 대응·분기 | 같은 시간의 다른 공간을 찾고 참가자에게 변경된 내용을 알린다. |
| 방문 이후 | 내 예약에서 날짜별 상태를 대조한다. 완료 회차의 시설 경험에 변화가 있으면 후기를 남긴다. |

표는 기본 흐름과 발생 가능한 분기를 함께 보여 주며 모든 사건이 한 방문에서 반드시 발생한다는 뜻은 아닙니다.

## 중단되는 지점

한 회차 예약으로 다른 날짜까지 확보됐다고 판단하지 않는다.

## 판단 순서

1. 같은 시간 이용
2. 강사 포함 수용 인원
3. 필수 시설·총액

> “매번 같은 시간에 진행하지만 예약은 날짜마다 따로 확인해야 해요.”

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
