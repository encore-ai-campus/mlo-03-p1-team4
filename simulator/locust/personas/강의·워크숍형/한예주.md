# 한예주 — 57세 · 강의·워크숍형

> 경력 전환 교육 강사 | 울산 울주군 | 가상 문답형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

경력 전환을 준비하는 성인들의 정기 학습 모임을 진행한다.

**주 기기:** 노트북

**숙련도:** 강의·온라인 예약 숙련

**예약·탐색 성향:** 회차별 재이용·정시 운영·조기 확정

**개인의 일정·이동·판단 조건:** 단체의 이동 동의가 있어야 다른 구를 검토하고 날짜별 예약 상태를 따로 본다.

## 지역을 고르는 방식

- 주 활동 지역: 울산 울주군
- 첫 검색: 울산 → 울주군
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '울산 → 남구'로 지역을 직접 바꿔 비교한다.

## 가상 문답 메모

질문에 대한 요지를 정리한 가상 문답입니다. 실제 사용자의 발언이나 인터뷰 결과로 인용하지 않습니다.

### 어떤 결과를 원하나요?

참가자가 익숙한 시간과 환경에서 수업을 진행한다.

### 무엇을 우선해서 보나요?

1. 같은 시간 이용
2. 강사 포함 수용 인원
3. 필수 시설·총액

### 검색과 비교는 어떻게 하나요?

시·도 '울산'에서 시·군·구 '울주군'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다.

이전에 쓴 공간을 먼저 보고 회차별 날짜의 빈 칸을 따로 확인한다.

### 결정하거나 멈추는 기준은요?

**결정 기준:** 해당 회차 조건이 맞으면 카드 모의 결제로 개별 확정한다.

**중단 기준:** 한 회차 예약으로 다른 날짜까지 확보됐다고 판단하지 않는다.

### 예상하지 못한 상황에는 어떻게 대응하나요?

정기적으로 쓰던 시간 중 이번 회차만 마감된다. 이 경우 같은 시간의 다른 공간을 찾고 참가자에게 변경된 내용을 알린다.

### 방문 이후에는 무엇을 하나요?

내 예약에서 날짜별 상태를 대조한다. 완료 회차의 시설 경험에 변화가 있으면 후기를 남긴다.

## 문답의 사실 조건

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 강의실 |
| 전체 인원 | 9명 |
| 이용 시간 가정 | 토요일 10~12시, 2시간 |
| 준비·확정 시점 | 각 회차 2~3주 전 |
| 총예산 | 90,000원 · 전체 대여료 상한 |

> “매번 같은 시간에 진행하지만 예약은 날짜마다 따로 확인해야 해요.”

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
