# 도현서 — 전남광주통합특별시 목포시

> 43세 · 독립 외국어 강사 | 강의·워크숍형 | 행동 규칙형
> 예약형 · 조건이 맞을 때 회원으로 모의 결제, 불충족 시 종료 가능
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 회차별 재이용·정시 운영·조기 확정

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 전남광주통합특별시 목포시 |
| 첫 지역 검색 | 전남광주통합특별시 → 목포시 |
| 같은 시·도 내 대안 | 전남광주통합특별시 → 무안군로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 시·군이 달라지는 대안은 수강생 이동 동의 뒤 확인하고 고정 시간은 유지한다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 상황과 목표

주말 회화 수업을 회차마다 별도 예약해 진행한다.

**목표:** 참가자가 익숙한 시간과 환경에서 수업을 진행한다.

**성향:** 회차별 재이용·정시 운영·조기 확정

## 입력 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 강의실 |
| 전체 이용 인원 | 9명 |
| 희망 시간 | 토요일 10~12시 · 2시간 |
| 준비·확정 시점 | 각 회차 2~3주 전 |
| 총예산 | 85,000원 · 공간 대여 전체 금액의 상한·실제 가격 아님 |
| 확인할 시설 | 화이트보드·의자/테이블 |

## 조건 → 행동

| 상황 | 선택 |
| --- | --- |
| 우선 지역이 선택 가능 | 지역 선택에서 전남광주통합특별시 → 목포시 경로를 적용하고 9명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다. |
| 지역이 미표시되거나 결과가 없음 | 전남광주통합특별시 → 무안군로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 결정 조건을 확인함 | 해당 회차 조건이 맞으면 카드 모의 결제로 개별 확정한다. |
| 불일치·보류 조건에 해당 | 한 회차 예약으로 다른 날짜까지 확보됐다고 판단하지 않는다. |
| 정기적으로 쓰던 시간 중 이번 회차만 마감된다. | 같은 시간의 다른 공간을 찾고 참가자에게 변경된 내용을 알린다. |

## 비교 과정

이전에 쓴 공간을 먼저 보고 회차별 날짜의 빈 칸을 따로 확인한다.

1. 같은 시간 이용
2. 강사 포함 수용 인원
3. 필수 시설·총액

## 종료 상태와 이후 행동

내 예약에서 날짜별 상태를 대조한다. 완료 회차의 시설 경험에 변화가 있으면 후기를 남긴다.

> “매번 같은 시간에 진행하지만 예약은 날짜마다 따로 확인해야 해요.”

규칙은 이 개인 시나리오의 가정이며 확률 모델이나 모든 지역 사용자의 행동 법칙이 아닙니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.
