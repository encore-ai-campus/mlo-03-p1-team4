# 이예담 — 71세 · 강의·워크숍형

> 온라인 문학 강사 | 대구 동구 | 프로필 카드형
> 예약형: 조건 충족 시 회원으로 모의 결제, 불충족 시 종료 가능
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

온라인으로 열던 시 읽기 수업을 처음 대면으로 진행한다.

**주 기기:** 노트북

**숙련도:** 온라인 문학 강좌 운영 숙련·대면 장소는 처음

**예약·탐색 성향:** 첫 대면 운영·상세 안내·충분한 사전 확인

**개인의 일정·이동·판단 조건:** 디지털 숙련과 공간 운영 경험이 같다고 생각하지 않고 입장·시설 안내를 읽는다.

## 지역을 고르는 방식

- 주 활동 지역: 대구 동구
- 첫 검색: 대구 → 동구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '대구 → 북구'로 지역을 직접 바꿔 비교한다.

> “수업 내용보다 공간을 빌려 사람을 맞는 절차가 더 낯설어요.”

## 목표 카드

처음 준비하는 대면 수업의 입장부터 정리까지 이해하고 예약한다.

## 이용 조건 카드

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 강의실 |
| 전체 인원 | 8명 |

| 준비·확정 시점 | 2~3주 전 |

## 선택 카드

1. 구체적인 이용 안내
2. 강사 포함 정원·시설
3. 총액

| 행동 | 선택 |
| --- | --- |
| 검색 | 시·도 '대구'에서 시·군·구 '동구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 비교 | 소수 후보의 안내와 교육 이용 후기를 천천히 읽는다. |
| 결정 | 운영 과정을 충분히 이해하면 카드 모의 결제로 확정한다. |
| 중단 | 필수 이용 조건을 이해하기 어려우면 서두르지 않고 보류한다. |

## 돌발 상황 카드

**상황:** 시설 표시는 있지만 본인의 수업 방식에 맞는지 판단이 어렵다.

**대응:** 필수 조건을 정리해 안내로 확인할 수 있는 후보와 비교한다.

**이후:** 내 예약과 개인 진행표를 맞춘다. 완료 후 처음 운영하는 사람에게 도움이 될 경험을 남긴다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
