# 페르소나 188 — 강다온별

- **상태:** 합성 사용자 시나리오 · 실제 인물/계정 아님
- **기본 프로필:** 만 19세, 대학 신입생 · 직업: 음악 강사 · 주 활동 지역: 부산 수영구
- **이용 목적:** 아이와 보호자가 함께하는 만들기 활동
- **주요 공간:** 스튜디오 · **인원:** 3명 · **희망 시간대:** 토요일 오전 09~12시
- **탐색 성향:** 후기와 별점을 읽고 모임에 맞는 분위기인지 살핀다
- **제약/확인 사항:** 빔프로젝터나 대형 화면이 필요하다

## 시작 흐름

1. 강다온별 계정이 있는지 로그인 화면에서 확인한다. **기존 회원이 아니면 이 시나리오의 첫 행동으로 회원가입을 시도한다.** 가입이 성공하면 해당 계정으로 로그인하고 이어서 진행한다.
2. 가입 또는 로그인이 실패하면 오류 안내를 확인하고, 비밀번호 재설정이나 다른 계정 등 기준에 없는 흐름을 임의로 만들지 않는다. 테스트 실행자는 환경에서 허용된 합성 계정만 사용한다.
3. 메인에서 공간 검색으로 이동해 지역은 부산 수영구, 공간 유형은 스튜디오로 설정해 살핀다. 필요하면 시설·인원·날짜 조건을 조정한다.
4. 검색 결과에서 가격, 후기, 시설, 위치 중 이 페르소나의 우선순위에 따라 후보를 비교하고 공간 상세를 확인한다.
5. 희망 시간대는 토요일 오전 09~12시이다. 날짜별 시간 칸에서 연속 이용 가능 여부를 확인한다. 예약 의향: 조건에 맞는 공간과 연속 빈 시간 칸을 찾으면 모의 결제까지 진행할 의향이 있다
6. 내 예약에서 예약 상태와 결제 정보를 확인한다.

## 완료 기준

- 가입/로그인 결과와 실패 시 안내를 확인한다.
- 검색 결과가 지역·유형·인원·시설 조건과 어떻게 맞는지 확인한다.
- 예약 의사가 있는 경우에만 이용 시간과 총액을 확인한 뒤 **한 번 결제(모의 결제)**로 예약한다. 결제 화면 진입만으로 예약이 생성된다고 가정하지 않는다.
- 예약 후에는 내 예약에서 상태를 확인한다. 취소가 필요한 경우 이용 시작 전인지 확인하고 취소 흐름을 따른다.
- 실제 이메일·전화번호·비밀번호 같은 개인정보는 문서나 실행 기록에 적지 않는다.
