## 2. 생활 배경과 이용 상황

고정 수강생들과 토요일 오전 회화 수업을 연다. 장소가 바뀌면 수강생이 혼란스러워하므로 검증한 공간을 선호하며, 현재 서비스에서는 수업 회차마다 날짜를 따로 예약한다.

## 3. 목표와 우선순위

- 수강생이 익숙한 지역과 시설로 수업을 유지한다.
- 수업 시작·종료 시각을 정확히 지킨다.

의사결정 기준은 다음 순서로 적용합니다.

1. 이전에 이용한 공간의 같은 시간
2. 화이트보드·의자/테이블
3. 수용 인원과 총액

## 4. 대표 이용 조건

아래 조건은 이 인물의 한 가지 대표 사례이며, 해당 유형 전체의 평균을 뜻하지 않습니다.

| 조건 | 구체적인 가정 |
| --- | --- |
| 공간 | 강의실 |
| 인원 | 강사 포함 9명 |
| 시간 | 토요일 10~12시, 2시간 |
| 예약 시점 | 각 회차 이용 2~3주 전 |
| 예산 | 회당 총액 8만 원 이내 |
| 조정 가능 범위 | 수업 시간은 고정, 공간 변경은 차선책 |

## 5. 검색부터 예약 확인까지

1. 기존 공간 이름을 검색해 다음 수업 날짜를 연다.
2. 해당 회차의 10~12시 연속 칸을 확인한다.
3. 인원과 시설 안내가 바뀌지 않았는지 읽는다.
4. 카드 모의 결제로 해당 회차만 예약한다.
5. 내 예약에서 날짜별로 확정됐는지 확인해 개인 수업 달력에 옮긴다.

## 6. 결정 기준과 중단 이유

**예약을 결정하는 조건:** 익숙한 공간이 같은 시간에 가능하면 다른 후보를 비교하지 않고 확정한다.

**중단·보류 이유:** 한 회차가 예약됐다는 이유로 나머지 주차도 확보된 것으로 판단하지 않는다.

## 7. 예약 충돌·일정 변경·이용 후 행동

**다른 사람이 먼저 예약한 경우:** 같은 시간에 가능한 강의실을 찾고 수강생에게 변경된 장소를 알린다.

**일정·인원 변경:** 수업이 취소되면 해당 날짜 예약만 시작 전에 취소하고 나머지 회차 내역은 따로 확인한다.

**이용 후 후기:** 매번 반복 작성하기보다 시설이나 안내가 달라진 경우에 구체적으로 남긴다.

## 8. 불편과 필요한 도움

**예상하는 불편**

- 여러 날짜의 예약 여부를 혼동함
- 기존 공간이 마감되면 같은 조건을 새로 확인해야 함

**서비스가 도와야 할 부분**

- 내 예약에서 회차별 날짜·시간·상태를 명확히 구분
- 검색 지역과 시설 조건을 유지한 대안 탐색

## 9. 관찰할 수 있는 행동 가설

같은 공간에 날짜만 바꿔 개별 예약이 반복된다. 이는 중복 요청이 아니라 서로 다른 회차다.

행동 기록은 이 가설을 검토하는 단서입니다. 검색 횟수나 종료 지점만으로 이용자의 감정·동기·중단 이유를 확정하지 않고 인터뷰 등으로 확인합니다.

## 10. 대표 인용문

> “수강생이 익숙한 곳에서 매번 같은 시간에 수업하는 게 가장 편해요.”

## 서비스 기준과 문서 출처

다락큐브의 검색·공간 상세·시간 조회는 비회원도 이용할 수 있고, 예약은 회원이 모의 결제로 확정합니다. 금액은 시간당 가격 × 이용 시간이며 예산 숫자는 예시입니다. 예약형 사례는 공간별 최소 이용시간 이상, 최대 4시간, 영업시간 안의 연속된 정수 시각을 전제로 합니다. 결제 화면 진입은 시간 확보를 뜻하지 않습니다.

시설 필터와 이용 안내를 구분합니다. 시설이 있다는 표시만으로 세부 성능·반입 규칙·주차 가능 대수·활동 허용을 추정하지 않습니다. 공간 그림은 일러스트이며 실제 사진을 전제로 하지 않습니다.
