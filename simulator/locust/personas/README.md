# 다락큐브 페르소나 파일 안내

2026-11-09 · 기존 300명과 추가 시나리오 200명을 유형별 폴더에 합쳐 총 500명입니다. 예약형 409명과 검색 전용 91명입니다.

기존 300명은 이름 파일, 추가 200명은 번호 파일로 저장했습니다. 유형별 폴더에는 두 묶음을 함께 수록합니다. 나이대별·지역별 목록은 기존 300명만 다룹니다.

페르소나는 한 사람당 Markdown 파일 하나로 작성합니다. 아래 유형별 폴더에서 500명 전체의 개인 파일을 찾을 수 있습니다.

모든 인물과 예산·감정·시나리오는 설계용 가설입니다. 나이·직업으로 행동을 자동 결정하지 않습니다. 예약형도 조건이 맞지 않으면 종료할 수 있고, 검색 전용 인물은 해당 시나리오에서 시간 선택·예약 시도·결제를 하지 않습니다. 가상 인터뷰는 실제 사용자 인터뷰 기록이 아닙니다.

## 활용 기준

- 카드형은 빠른 공유, 인터뷰형·공감 지도형은 동기 이해, 여정형·시나리오형은 흐름 검토, 행동 규칙형은 시뮬레이션 설계에 활용합니다.
- 개인 문서의 예산·이용 시간은 대표 사례이며 시장 통계나 실제 시설 재고를 뜻하지 않습니다. 희망 조건이 최대 이용시간 등 서비스 제약과 맞지 않는 검색 전용 사례도 포함했습니다.
- 반복 이용은 날짜마다 개별 예약합니다. 후보 전달은 브라우저 주소·개인 메모 등 외부 행동이며 자동 후보 보관·정기 예약·호스트 문의·예약 대기 등 정의되지 않은 기능을 전제하지 않습니다.
- 예약은 모의 결제이며 시간 홀딩이 없습니다. 수용 인원에는 동행자와 진행자를 포함합니다. 취소와 후기 작성은 서비스 규칙을 따릅니다.
- 정상 조사 종료·위임·조건 불일치·정보 부족·가입 부담·외부 대안 확보·탐색 중단을 모두 실패한 결제로 보지 않습니다. 로그만으로 종료 이유를 확정하지 않습니다.
