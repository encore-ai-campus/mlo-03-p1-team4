# 공준호 — 강원특별자치도 평창군

> 30세 · 영상 작업 프리랜서 | 검색 전용 | 행동 규칙형
> 검색 전용 · 이번 방문은 시간 칸 선택·예약 시도·결제 없음
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 필수 이용 정보 우선·미확인 시 보류

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 강원특별자치도 평창군 |
| 첫 지역 검색 | 강원 → 평창군 |
| 같은 시·도 내 대안 | 강원 → 강릉시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 일러스트와 기본 시설로 필수 환경을 확인할 수 없어 이번에는 예약하지 않는다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 상황과 목표

작업에 필요한 채광과 실제 배치 정보를 찾는다.

**목표:** 계획에 필요한 세부 이용 정보를 확인할 수 있는지 판단한다.

**성향:** 필수 이용 정보 우선·미확인 시 보류

## 입력 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 스튜디오 |
| 전체 이용 인원 | 4명 |
| 희망 시간 | 계획상 평일 14~16시 · 2시간 |
| 준비·확정 시점 | 이용 검토 단계, 검색만 |
| 총예산 | 85,000원 · 조사용 가정·계획 상한이며 실제 지출 없음 |
| 확인할 시설 | 의자/테이블·전기 |

## 조건 → 행동

| 상황 | 선택 |
| --- | --- |
| 우선 지역이 선택 가능 | 지역 선택에서 강원 → 평창군 경로를 적용하고 4명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다. |
| 지역이 미표시되거나 결과가 없음 | 강원 → 강릉시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 결정 조건을 확인함 | 필수 조건이 확인되는지 판단하는 것 자체가 이번 탐색의 결과다. |
| 불일치·보류 조건에 해당 | 이번 후보에서 필수 정보가 부족해 시간 선택·가입·결제 없이 종료한다. |
| 시설 이름은 있으나 본인에게 필요한 세부 이용 정보는 없다. | 미확인을 가능으로 추정하지 않고 다른 정보원이나 장소를 검토한다. |

## 비교 과정

상세 안내와 후기를 읽고 필요한 정보와 현재 확인 가능한 정보를 구분한다.

1. 필수 정보의 확인 가능성
2. 인원·기본 시설
3. 일정·예산

## 종료 상태와 이후 행동

동행자에게 확인하지 못한 조건을 알린다. 이용 완료 예약이 없어 후기를 쓰지 않는다.

> “조건이 확인되지 않았는데 괜찮을 거라고 생각하고 예약할 수는 없어요.”

규칙은 이 개인 시나리오의 가정이며 확률 모델이나 모든 지역 사용자의 행동 법칙이 아닙니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.

**자료 기준:** 프로젝트 `db/seed/regions.csv`·`db/seed/README.md`의 지역 선택값과 `docs/산출물_01_요구사항명세서.md`의 기능 범위. 행정구역 표기 근거와 지역별 파일 목록은 [지역별 목록](../지역별_목록.md)을 참고합니다.
