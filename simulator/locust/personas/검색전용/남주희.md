# 남주희 — 프로필 카드형

> 검색 전용 | 42세 · 소규모 교육업체 기획자 | 인천
> 검색 전용 · 이번 시나리오에서 예약·결제하지 않음
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

> “영업시간 안이더라도 여섯 시간을 한 번에 예약할 수 있는지는 따로 봐야 하네요.”

## 이 사람을 기억하는 한 줄

**장시간 일괄 이용 필요·서비스 조건 불일치**

하루 워크숍 장소를 조사하지만 원하는 이용 시간은 여섯 시간이다. 현재 서비스의 한 예약 최대 네 시간과 맞지 않아 이 방문에서는 예약하지 않으며, 시간을 나눠 한도를 우회할 계획도 세우지 않는다.

## 목표 카드

계획한 여섯 시간 워크숍을 현재 서비스에서 예약할 수 있는지 확인한다.

## 이용 조건 카드

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 강의실 |
| 인원 | 10명 |
| 시간 | 희망 10~16시, 6시간 — 현재 최대 4시간과 불일치 |
| 예약 시점 | 행사 3주 전 조사, 이번에는 예약하지 않음 |
| 총예산 | 계획 예산 30만 원, 결제 없음 |
| 조정 가능 범위 | 날짜 유연, 일괄 여섯 시간 이용은 필수 |

## 우선순위 카드

1. 한 번에 여섯 시간 이용 가능 여부
2. 10명 수용·발표 시설
3. 전체 행사 비용

## 행동을 빠르게 보기

| 단계 | 행동 |
| --- | --- |
| 찾기 | 지역·강의실·10명으로 후보를 찾는다. |
| 비교 | 상세와 시간 선택 안내에서 최대 이용 조건을 읽는다. |
| 결정 | 필요한 여섯 시간이 현재 예약 조건과 맞지 않음을 확인하는 것이 이번 탐색의 결론이다. |
| 중단 | 최대 네 시간 제약 때문에 시간 선택·모의 결제 없이 종료한다. |

## 돌발 상황 카드

**상황:** 운영시간은 길게 표시되지만 한 예약의 최대 이용 시간은 별도라는 점을 알게 된다.

**대응:** 영업시간과 예약 한도를 구분하고, 여섯 시간을 허용하는 별도 방식을 외부에서 검토한다.

**속마음:** 공간 자체가 마음에 들어도 행사 전체를 끊어서 운영할 수는 없다고 생각한다.

## 이 방문 이후

행사 운영 계획에 서비스 조건 불일치를 기록한다. 예약을 여러 건으로 나눠 확보하지 않는다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
