# 전시우 — 14세 · 검색 전용

> 중학생·지역 활동 참여자 | 전남광주통합특별시 북구 | 프로필 카드형
> 검색 전용: 이번 시나리오에서는 예약·결제를 하지 않음
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

청소년 활동을 준비하는 성인 담당자에게 보여 줄 공간 후보를 조사한다.

**주 기기:** 태블릿

**숙련도:** 검색 익숙·후보 기록에 관심

**예약·탐색 성향:** 후보 조사·예약자에게 위임·조회 후 종료

**개인의 일정·이동·판단 조건:** 본인은 안내와 가능한 시간만 조회하고 실제 예약 담당자가 다시 확인하도록 전달한다.

## 지역을 고르는 방식

- 주 활동 지역: 전남광주통합특별시 북구
- 첫 검색: 전남광주통합특별시 → 북구
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '전남광주통합특별시 → 동구'로 지역을 직접 바꿔 비교한다.

> “제가 결제할 건 아니고 예약할 사람이 고를 후보를 찾는 거예요.”

## 목표 카드

실제 예약자가 결정할 수 있도록 요청 조건에 맞는 후보를 정리한다.

## 이용 조건 카드

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 강의실·스터디룸 |
| 전체 인원 | 8명 |
| 이용 시간 가정 | 가정상 평일 14~16시, 2시간 |
| 준비·확정 시점 | 예약 담당자에게 후보만 전달 |
| 총예산 | 80,000원 · 조사용 가정·결제 없음 |
| 필요한 시설 | TV/프로젝터·의자/테이블 |

## 선택 카드

1. 요청받은 지역·시간·인원
2. 시설·총액
3. 명확한 안내

| 행동 | 선택 |
| --- | --- |
| 검색 | 시·도 '전남광주통합특별시'에서 시·군·구 '북구'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 비교 | 세 후보의 안내와 빈 시간은 조회만 하고 브라우저 주소와 조건을 개인 문서에 적는다. |
| 결정 | 요청 조건에 맞는 비교 가능한 후보를 전달하면 역할이 끝난다. |
| 중단 | 본인이 예약 담당자가 아니어서 예약·가입·결제 없이 정상 종료한다. |

## 돌발 상황 카드

**상황:** 후보를 전달하는 사이 조회했던 시간이 마감될 수 있다.

**대응:** 조회는 확보가 아님을 알리고 실제 예약자에게 다시 칸을 확인하도록 안내한다.

**이후:** 외부에서 결정자에게 후보를 전달한다. 별도 사용자의 예약을 자신의 행동으로 기록하지 않는다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
