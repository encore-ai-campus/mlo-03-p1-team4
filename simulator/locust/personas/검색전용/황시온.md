# 황시온 — 행동 규칙형

> 검색 전용 | 26세 · 도시공간 연구 수업을 듣는 대학원생 | 서울
> 검색 전용 · 이번 시나리오에서 예약·결제하지 않음
> 2026-11-06 · 가상 페르소나. 인물·예산·심리·인용문은 설계용 가정이며 실제 조사 기록이 아닙니다.

## 이 인물이 놓인 상황

수업 발표를 위해 지역별 공간 유형과 표시 가격이 어떻게 다른지 수동으로 살펴본다. 개인 모임을 계획하는 방문이 아니며 현재 서비스에서 관찰한 표본만 개인 문서에 정리한다.

**목표:** 몇 개 지역의 표시 가격·시설 차이를 비교할 관찰 자료를 모은다.

**성향:** 지역 비교 조사·예약 의도 없음

## 입력 조건

| 항목 | 대표 사례의 조건 |
| --- | --- |
| 공간 | 스터디룸·카페·강의실을 비교 |
| 인원 | 조사용 가정 4명 |
| 시간 | 비교 가정 2시간, 실제 날짜 없음 |
| 예약 시점 | 예약 계획 없음 |
| 총예산 | 지출 계획 없음, 표시된 총액 비교 |
| 조정 가능 범위 | 지역과 유형을 바꾸되 비교 가정은 유지 |

## 우선순위 — 숫자는 순서이며 점수가 아님

1. 비교 조건의 일관성
2. 시간당 가격과 최소 시간
3. 시설·유형별 차이

## 조건 → 행동 규칙

| 조건·상황 | 이 인물의 선택 |
| --- | --- |
| 지역을 변경함 | 비교 인원·시간 가정 유지 |
| 최소 시간이 다름 | 비교 조건 차이를 별도 기록 |
| 조사 사례가 충분함 | 예약 시도 없이 종료 |

## 기본 실행 흐름

1. 지역만 바꾸면서 같은 인원·유형 조건으로 수동 검색한다.
2. 후보의 가격·최소 시간·시설을 개인 표에 기록한다.
3. 발표에 필요한 관찰 사례를 모으면 검색 목적을 달성한 것으로 본다.

## 예외 처리 사례

**발생 상황:** 지역별로 후보 수가 달라 단순 평균이 전체 시세처럼 보일 수 있다.

**대응:** 관찰한 표본의 한계와 검색 조건을 함께 기록하고 전체 시장으로 일반화하지 않는다.

**종료·보류:** 조사 범위가 채워진 시점에 예약·가입·결제 없이 정상 종료한다.

## 종료 상태와 후속 행동

개인 발표 자료를 정리한다. 서비스에서 시간 칸을 선택하거나 예약을 시도하지 않는다.

**규칙 뒤의 동기:** 좋은 공간을 고르는 것보다 비교 과정이 일관되는지가 중요하다.

> “제가 쓸 곳을 찾는 게 아니라, 같은 조건에서 지역별 차이를 살펴보는 중이에요.”

여기서 정한 규칙은 행동 시나리오의 가정입니다. 실제 사용자가 같은 조건에서 반드시 이렇게 행동한다는 확률 모델은 아닙니다.

---

**해석 기준:** 예산·빈도·선택은 개인 시나리오의 가정입니다. 실제 지출이 발생하지 않는 모의 결제를 전제로 합니다. 검색 종료가 곧 불만을 뜻하지 않으며 감정·동기는 로그만으로 단정하지 않습니다.

**서비스 기준:** 검색·상세·시간 조회는 비회원도 가능하고 예약은 회원이 진행합니다. 공간별 최소 이용시간~최대 4시간, 영업시간 안의 연속 정수 시각을 사용합니다. 결제 전 홀딩은 없고 취소는 이용 시작 전입니다. 후기는 이용 완료 예약에 한해 정해진 작성 기간 안에 남깁니다. 장식 일러스트와 일반 시설 표시는 실제 사진·접근성·방음·활동 허용의 보증으로 해석하지 않습니다.
