# 임서준 — 충청남도 태안군

> 39세 · 행사 운영 프리랜서 | 검색 전용 | 가상 인터뷰 메모형
> 검색 전용 · 이번 방문은 시간 칸 선택·예약 시도·결제 없음
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 장시간 일괄 이용 필요·예약 한도 불일치

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 충청남도 태안군 |
| 첫 지역 검색 | 충남 → 태안군 |
| 같은 시·도 내 대안 | 충남 → 서산시로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 지역을 바꾸기 전에 영업시간과 최대 네 시간 예약 한도가 다르다는 점을 확인하고 종료한다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 가상 인터뷰의 문답 요지

아래는 가상 인물의 상황을 문답으로 요약한 기획 메모입니다. 실제 인터뷰나 관찰 기록으로 인용하지 않습니다.

### 어떤 일을 위해 공간을 찾나요?

한 장소에서 여섯 시간 연속 프로그램을 운영할 수 있는지 조사한다.

### 지역을 고르는 기준은 무엇인가요?

지역을 바꾸기 전에 영업시간과 최대 네 시간 예약 한도가 다르다는 점을 확인하고 종료한다.

### 무엇을 가장 먼저 확인하나요?

1. 희망 6시간과 예약 한도 일치 여부
2. 전체 인원 수용
3. 전체 행사 예산

### 실제로 어떻게 검색하고 비교하나요?

지역 선택에서 충남 → 태안군 경로를 적용하고 10명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다.

공간 영업시간과 한 예약의 최대 이용시간을 구분해 안내를 읽는다.

### 결정하거나 멈추는 조건은 무엇인가요?

**결정:** 희망 여섯 시간이 현재 최대 네 시간과 맞지 않음을 확인하는 것이 탐색 결과다.

**보류·종료:** 시간 한도 불일치로 선택·예약·결제 없이 종료한다.

### 예상과 다른 일이 생기면 어떻게 하나요?

공간의 영업시간은 길어도 한 예약의 최대 이용시간은 네 시간이다. 그 경우 예약을 쪼개 한도를 우회하지 않고 행사 계획이나 외부 대안을 검토한다.

## 진행자가 정리한 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 강의실 |
| 전체 이용 인원 | 10명 |
| 희망 시간 | 희망 평일 10~16시 · 6시간 |
| 준비·확정 시점 | 행사 3주 전 조사만 |
| 총예산 | 300,000원 · 조사용 가정·계획 상한이며 실제 지출 없음 |
| 확인할 시설 | TV/프로젝터·의자/테이블 |
| 서비스와 불일치 | 희망 6시간이 한 예약 최대 4시간을 초과하여 예약하지 않음 |

**방문 이후:** 개인 행사 계획에 조건 불일치를 적는다. 실제 예약을 생성하지 않는다.

> “영업시간 안이라고 필요한 여섯 시간을 한 번에 예약할 수 있는 건 아니네요.”

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.
