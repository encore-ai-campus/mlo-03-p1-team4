# 탁수빈 — 전남광주통합특별시 나주시

> 27세 · 교육 프로그램 연구원 | 검색 전용 | 사용자 여정형
> 검색 전용 · 이번 방문은 시간 칸 선택·예약 시도·결제 없음
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 예산 조사·날짜 미정·정상 종료

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 전남광주통합특별시 나주시 |
| 첫 지역 검색 | 전남광주통합특별시 → 나주시 |
| 같은 시·도 내 대안 | 전남광주통합특별시 → 남구로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 통합 시·도 아래의 시와 구를 수동 비교하되 공급이나 시세를 지역 전체로 단정하지 않는다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 출발점

다음 해 주민 프로그램 예산을 위해 후보의 표시 가격을 조사한다.

**도달하려는 결과:** 계획 중인 활동의 지역별 표시 가격과 최소 시간을 알아본다.

**성향:** 예산 조사·날짜 미정·정상 종료

## 여정과 분기

| 단계 | 행동·판단 |
| --- | --- |
| 1. 지역 선택 | 지역 선택에서 전남광주통합특별시 → 나주시 경로를 적용하고 6명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다. |
| 2. 비교 | 같은 인원·이용 시간 가정으로 후보를 수동 비교하고 개인 문서에 기록한다. |
| 3. 결정 | 계획서에 넣을 비용 범위와 조건을 정리하면 탐색 목표를 달성한다. |
| 4. 예상 밖 상황 | 지역마다 후보 수와 최소 시간이 달라 단순 비교하기 어렵다. |
| 5. 대응 | 조회한 조건과 표본의 한계를 함께 적고 지역 전체 시세로 일반화하지 않는다. |
| 6. 방문 이후 | 개인 계획서를 정리한다. 시간 칸 선택·예약 시도·후기 작성은 하지 않는다. |

표는 기본 흐름과 가능한 분기를 함께 표시합니다. 매 방문마다 모든 사건이 순서대로 발생한다는 뜻은 아닙니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.
