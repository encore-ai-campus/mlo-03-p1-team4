# 안태준 — 전북특별자치도 무주군

> 29세 · 기획 지원 직원 | 검색 전용 | 공감 지도형
> 검색 전용 · 이번 방문은 시간 칸 선택·예약 시도·결제 없음
> 기준일 2026-11-06 · 가상 인물입니다. 예산·지역 선택·심리·행동은 개인 설계 가정이며 해당 지역 주민이나 시장을 대표하는 조사 결과가 아닙니다.

**개인의 예약·탐색 성향:** 후보 조사·예약자에게 위임·조회 후 종료

## 지역과 검색 범위

| 구분 | 서비스 선택값·개인 기준 |
| --- | --- |
| 주 활동 지역 | 전북특별자치도 무주군 |
| 첫 지역 검색 | 전북 → 무주군 |
| 같은 시·도 내 대안 | 전북 → 진안군로 직접 재선택한다. 본인과 동행자의 이동 가능 여부를 확인하며 자동 인근 지역 추천을 전제하지 않는다. |
| 시·도 경계를 넘는 대안 | 없음 · 해당 인물은 명시한 시·도 안에서 비교 |

**이 사람의 이동·지역 판단:** 두 군을 가까운 대안이라고 단정하지 않고 요청받은 비교 대상과 조회 조건만 전달한다.

지역은 서비스의 `regions.csv` 시·도/시·군·구 선택값을 사용했습니다. 일반구·읍면동을 추가 검색 필터로 가정하지 않습니다. 행정구역명이 같아도 시·도가 다르면 다른 검색 대상입니다.

## 지도의 중심 인물

다른 담당자가 확정할 교육 공간 후보를 조사한다.

**바라는 결과:** 실제 예약자가 결정할 수 있도록 요청 조건에 맞는 후보를 정리한다.

## 말하는 것

> “제가 결제할 건 아니고 예약할 사람이 고를 후보를 찾는 거예요.”

## 생각하는 것

**후보 조사·예약자에게 위임·조회 후 종료**를 우선한다.

1. 요청받은 지역·시간·인원
2. 시설·총액
3. 명확한 안내

## 하는 행동

1. 지역 선택에서 전북 → 무주군 경로를 적용하고 8명과 목적에 맞는 유형·시설을 지정한다. 날짜가 정해진 경우에만 계획한 날짜·시간 조건도 입력한다.
2. 세 후보의 안내와 빈 시간은 조회만 하고 브라우저 주소와 조건을 개인 문서에 적는다.
3. 요청 조건에 맞는 비교 가능한 후보를 전달하면 역할이 끝난다.

## 감정과 부담의 가설

본인의 우선 조건인 ‘요청받은 지역·시간·인원’을 확인해야 안심한다. 후보를 전달하는 사이 조회했던 시간이 마감될 수 있다. 같은 상황에서 결정을 서두르기보다 조건을 다시 살피려 한다.

**취하는 대응:** 조회는 확보가 아님을 알리고 실제 예약자에게 다시 칸을 확인하도록 안내한다.

**선택을 멈추는 경계:** 본인이 예약 담당자가 아니어서 예약·가입·결제 없이 정상 종료한다.

## 감정과 별도로 확인할 조건

| 이용 조건 | 개인 시나리오의 가정 |
| --- | --- |
| 목적에 맞는 공간 | 강의실·스터디룸 |
| 전체 이용 인원 | 8명 |
| 희망 시간 | 평일 14~16시 · 2시간 |
| 준비·확정 시점 | 예약 담당자에게 후보만 전달 |
| 총예산 | 100,000원 · 조사용 가정·계획 상한이며 실제 지출 없음 |
| 확인할 시설 | TV/프로젝터·의자/테이블 |

**방문 이후:** 외부에서 결정자에게 후보를 전달한다. 별도 사용자의 예약을 자신의 행동으로 기록하지 않는다.

생각과 감정은 가상 설정입니다. 체류 시간이나 검색 범위만으로 실제 감정을 판단하지 않습니다.

## 지역 검색에서 오해하지 않을 점

- 이 지역에 실제 활성 공간이나 빈 시간이 있다는 뜻은 아닙니다. 화면에는 활성 공간이 있는 지역만 표시되므로 미표시·빈 결과 때는 위의 허용 범위를 확인하거나 종료합니다. 지역 선택 가능 여부와 전체 지역의 공급 유무를 동일시하지 않습니다.
- 검색 범위 확대는 개인이 합의한 대안입니다. 거리순·자동 인근 추천·교통편·이동시간 계산 기능을 전제하지 않습니다. 개인 이동 판단은 이용자가 별도로 확인합니다.
- 금액은 시나리오의 총예산입니다. 실제 지역별 시세가 아니며 계산 기준은 시간당 가격 × 선택 시간입니다. 시설 이름으로 방음·접근성·반입 허용·주차 가능 대수를 추정하지 않습니다.

**서비스 기준:** 예약형은 공간별 최소 시간 이상 최대 4시간의 연속 정수 시각과 영업시간을 지킵니다. 결제는 모의 결제이고 결제 전 홀딩은 없습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 기간 안에서 진행합니다. 검색 전용은 해당 시나리오에서 예약을 생성하지 않습니다.
