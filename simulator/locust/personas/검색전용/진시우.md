# 진시우 — 59세 · 검색 전용

> 지역 활동 기획자 | 경북 안동시 | 행동 규칙형
> 검색 전용: 이번 시나리오에서는 예약·결제를 하지 않음
> 2026-11-06 · 연령 다양성을 검토하기 위한 가상 페르소나입니다. 실제 인터뷰·이용자 통계·시장 비율이 아닙니다.

## 이 인물의 생활과 디지털 경험

다음 분기 주민 활동 계획서에 넣을 대여 비용을 조사한다.

**주 기기:** 노트북

**숙련도:** 자료 조사·표 정리 숙련

**예약·탐색 성향:** 예산 조사·날짜 미정·정상 종료

**개인의 일정·이동·판단 조건:** 표시된 일부 후보의 가격을 지역 전체 시세로 일반화하지 않고 조사만 마친다.

## 지역을 고르는 방식

- 주 활동 지역: 경북 안동시
- 첫 검색: 경북 → 안동시
- 허용한 대안: 본인과 동행자가 이동에 동의하면 '경북 → 예천군'로 지역을 직접 바꿔 비교한다.

## 목표와 입력 조건

계획 중인 활동의 지역별 표시 가격과 최소 시간을 알아본다.

| 조건 | 대표 시나리오 |
| --- | --- |
| 공간 유형 | 스터디룸·강의실 |
| 전체 인원 | 6명 |
| 이용 시간 가정 | 가정상 주말 14~16시, 2시간 |
| 준비·확정 시점 | 계획서 작성 전 조사만 |
| 총예산 | 90,000원 · 조사용 가정·결제 없음 |
| 필요한 시설 | 의자/테이블 |

## 우선순위

1. 비교 조건의 일관성
2. 가격·최소 시간
3. 인원과 지역

## 조건 → 행동

| 상황 | 행동 |
| --- | --- |
| 먼저 볼 지역을 선택할 수 있음 | 시·도 '경북'에서 시·군·구 '안동시'를 고르고, 인원·공간 유형·필요 시설을 적용한다. 실제 일정이 정해진 경우에만 날짜·시작 시간·이용 시간을 입력한다. |
| 해당 지역이 미표시되거나 결과가 없음 | 본인과 동행자가 이동에 동의하면 '경북 → 예천군'로 지역을 직접 바꿔 비교한다. |
| 조건을 검토함 | 같은 인원·이용 시간 가정으로 후보를 수동 비교하고 개인 문서에 기록한다. |
| 결정 기준에 부합 | 계획서에 넣을 비용 범위와 조건을 정리하면 탐색 목표를 달성한다. |
| 불일치·중단 기준에 해당 | 실제 일정이 없으므로 정보가 모이면 예약·가입·결제 없이 정상 종료한다. |
| 지역마다 후보 수와 최소 시간이 달라 단순 비교하기 어렵다. | 조회한 조건과 표본의 한계를 함께 적고 지역 전체 시세로 일반화하지 않는다. |

## 종료 이후

개인 계획서를 정리한다. 시간 칸 선택·예약 시도·후기 작성은 하지 않는다.

> “오늘 예약하려는 게 아니라 계획에 넣을 비용부터 알아보는 중이에요.”

이 규칙은 해당 인물의 대표 시나리오입니다. 실제 행동 확률이나 해당 연령 전체의 법칙은 아닙니다.

## 문서와 서비스의 기준

- 나이는 배분을 위한 구분입니다. 디지털 숙련도·직업·예산·이용 목적·도움 필요 여부는 각 인물의 별도 가정이며 나이만으로 결정하지 않습니다.
- 예산은 전체 대여료의 가상 상한입니다. 실제 가격은 시간당 가격 × 선택 시간입니다. 특정 지역의 실제 재고·빈 시간·가격을 보장하지 않습니다. 화면에서 지역이 선택되지 않으면 합의한 범위를 검토하거나 종료합니다.
- 비회원은 검색·상세·시간 조회를 하고, 예약형 인물은 회원으로 모의 결제를 진행합니다. 10대 사례는 서비스의 만 14세 이상 가입 기준을 충족하도록 설정했습니다. 예약은 공간별 최소 시간 이상 최대 4시간, 영업시간 안의 연속 정수 시각을 전제로 합니다.
- 결제 화면에 진입해도 시간이 확보되지 않습니다. 취소는 이용 시작 전, 후기는 이용 완료 예약과 정해진 작성 기간 안에서 진행합니다. 시설 표기와 일러스트로 접근성·방음·반입 허용·주차 가능 대수를 추정하지 않습니다.
