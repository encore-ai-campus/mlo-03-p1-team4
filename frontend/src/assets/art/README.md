# assets/art — 공간 일러스트

공간 사진은 크롤링하지 않습니다. 이 폴더의 유형별 일러스트는 로그인 화면과 사진 로딩 실패·유형/공간 ID 누락 때 대체 이미지로 씁니다. 화면에서는 `src/components/domain/RoomArt.vue`가 표시합니다(11-06부터 이미지 파일, 그 전에는 같은 컴포넌트가 도형으로 그렸음).

화면의 공간 카드에는 `frontend/public/photos/`의 CCL 분위기 참고 사진도 연결되어 있습니다. 5개 유형마다 8장씩이며 실제 등록 공간을 나타내지 않습니다. `RoomArt.vue`가 유형과 venue ID를 해시해 고정 선택하므로 새로고침해도 같은 공간은 같은 사진을 씁니다. 상세 갤러리는 칸 번호를 선택 키에 더해 서로 다른 컷을 고릅니다. 출처·라이선스·수정 내역은 [SOURCES.md](../../../public/photos/SOURCES.md), 사용자용 크레딧은 `/photos/credits.html`입니다. 이미지 API `art:<종류>-<색>` 계약은 그대로입니다.

## 어떤 그림이 나오나

**API 계약은 그대로입니다.** `venue_images.url`·`POST /internal/venues`는 `art:<종류>-<색>`(예: `art:group-1`)만 받습니다.

1. 공간 유형(`category.code`)을 알면 그 유형 그림을 씁니다. 크롤러는 스터디룸에도 인원에 따라 `duo`·`lounge`·`group`·`seminar`·`meeting`을 주므로 종류만으로는 유형을 알 수 없습니다(`crawler/README.md`).
2. 유형을 모를 때만 종류로 고릅니다: booth·duo·group → 스터디룸, meeting·seminar → 강의실, lounge·cafe → 카페, studio → 스튜디오, partyroom → 파티룸.
3. 색 `1`은 같은 그림을 좌우로 뒤집어 보여 줍니다(같은 유형 카드가 나란히 있어도 덜 똑같아 보이게). 그래서 **그림 안에 글자·로고·숫자를 넣지 않습니다.**

## 이미지 규격 (새로 구해 올 때)

### 원본 한 가지만 받으면 됩니다

| 항목 | 값 |
| --- | --- |
| 크기 | **1600×1040px** (가로:세로 = 400:260 = 20:13) |
| 형식 | JPEG(품질 80~85) 또는 WebP, 장당 **300KB 이하** |
| 화풍 | 지금 5장과 같은 화풍(따뜻한 낮빛, 나무·뼈색·올리브 계열, 사람 없음) |
| 넣지 않는 것 | 글자·간판·로고·숫자(좌우 반전되면 뒤집혀 보임), 실제 업체가 알아볼 수 있는 내부, 사람 얼굴 |
| 출처 | 직접 생성(이미지 생성 도구) 또는 확인된 CCL 사진만. **스페이스클라우드·쉐어잇 등 크롤링 대상 사이트 사진은 쓰지 않음**(루트 `AGENTS.md`) |
| 이름 | `venue-<유형>.jpg`, 여러 장이면 `venue-<유형>-2.jpg`처럼 번호 |

원본만 구해 오면 됩니다. 지금은 모든 자리에 원본을 그대로 쓰고, 첫 화면이 무거우면 카드·썸네일용 작은 크기를 프론트가 원본에서 만듭니다.

### 화면별로 실제 보이는 크기

1280px 데스크톱과 375px 폰에서 잰 값입니다(CSS px). 폰·레티나는 2배 픽셀이 필요하니 오른쪽 '필요 픽셀'을 기준으로 봅니다.

| 화면 | 자리 | 데스크톱 | 폰(375) | 필요 픽셀(2배) | 잘리는 방식 |
| --- | --- | --- | --- | --- | --- |

| 메인 | 유형 바로가기 작은 칸 4개 | 112×108 | 112×약 100 | 240×240 | **거의 정사각형으로 잘림** → 중요한 것은 가운데에 |
