# assets/art — 공간 일러스트

공간 사진은 크롤링하지 않으므로, 모든 공간 이미지는 일러스트를 돌려 씁니다. 일러스트는 SVG 파일이 아니라 Vue 컴포넌트 `src/components/domain/RoomArt.vue`가 그립니다(디자인 캔버스 RoomArt와 같은 그림 로직).

```vue
<RoomArt kind="studio" :tone="1" />
```

| kind | 그림 | 쓰는 유형 |
| --- | --- | --- |
| booth | 1인 부스 | 스터디룸 (최대 1~2명) |
| duo, lounge | 2인 테이블, 창가 라운지 | 스터디룸 (3~4명) |
| group, seminar | 화이트보드 그룹룸, TV 세미나룸 | 스터디룸 (5~8명) |
| meeting | 빔프로젝터 회의실 | 스터디룸 (9명 이상) |
| studio | 호리존·조명·카메라 | 스튜디오 |
| cafe | 카운터·메뉴판·원형 테이블 | 카페 |
| cinema | 스크린·좌석 두 줄 | 영화관 |
| partyroom | 풍선·가랜드·케이크 | 파티룸 |

`tone`은 0(기본)·1(벽 색 변형). 10종 × 2색 = 20가지입니다.

- 백엔드는 `room_images.url`에 `art:studio-1`처럼 종류와 색을 저장하고, 프론트가 이를 `kind`·`tone`으로 풀어 씁니다(이전 문서의 `/art/*.svg` 경로 대신 — DB 담당과 형식 확정 필요).
- 이 폴더에는 나중에 진짜 이미지(로고, 실사 사진)가 생기면 둡니다.
